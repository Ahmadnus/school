## 2. مخطط الداتابيز الموحّد

> **محدَّث بقرارات المالك** (انظر §7-أ). الجداول المشتركة مذكورة مرة واحدة.
> 🔶 = ما زال مفترضاً بلا قرار. ✅ = أُقرّ صراحةً.

### 2.1 المدرسة والبنية الأكاديمية

| الجدول | الأعمدة |
|---|---|
| `schools` | id، الاسم، البريد، الشعار، **`currency`** ✅(18-ب) |
| `academic_years` | id، school_id، الاسم، بداية، نهاية، is_current |
| `terms` | id، academic_year_id، الاسم، بداية، نهاية، is_current |
| `grades` | id، school_id، الاسم، الترتيب — **بلا حقل رسوم** ✅(1-أ) |
| `sections` | id، grade_id، **`academic_year_id`** ✅(19-ب)، الاسم، السعة، الترتيب |
| `holidays` | id، school_id / academic_year_id، الاسم، بداية، نهاية |

> **أثر 19-ب**: الشعبة تُنشأ لكل سنة أكاديمية. مفتاح فريد مقترح: `(grade_id, academic_year_id, name)`.

### 2.2 الأشخاص والتسجيل

| الجدول | الأعمدة |
|---|---|
| `students` | id، school_id، الاسم الأول/الأخير، **`student_number`** (تسلسلي داخل المدرسة، قابل للبحث) ✅(20-أ)، **`external_id`** (اختياري) ✅(20-أ)، تاريخ الميلاد، الجنس، الجنسية، فصيلة الدم، العنوان، المبنى/الفرع، ملاحظات طبية، الحالة — **بلا `section_id`** ✅(19-ب) |
| `student_enrollments` ✅(19-ب) | id، student_id، section_id، academic_year_id، **نطاق التسجيل** (سنة كاملة/فصل أول/فصل ثانٍ)، تاريخ التسجيل، الاشتراك في النقل، الحالة |
| `guardians` | id، school_id، الاسم، الهاتف، الحالة |
| `student_guardians` ✅(14-أ) | student_id، guardian_id، **`relation`** (أب/أم/وصي)، **`is_primary`** — **قيد فريد جزئي**: `UNIQUE(student_id) WHERE is_primary` |
| `users` | id، school_id، الاسم الأول/الأخير، الهاتف، البريد، كلمة المرور، **`role`** ∈ `{super_admin, admin, teacher, driver}` ✅(6-أ)، **`specialty` TEXT** ✅(17-أ)، الحالة |
| `supervisor_scopes` ✅(7-أ) | staff_id، **section_id** |
| `teacher_assignments` ✅(15-ب) | id، staff_id، subject_id، section_id — **يستبدل** `teacher_sections` و`teacher_subjects` |
| `student_imports` | id، الملف، الحالة، عدد الأسطر، النتيجة 🔶 |

> **أثر 19-ب على كل ما يلي**: أي شيء «خاص بالطالب في سنة معيّنة» يرتبط بـ`student_enrollments` أو بـ(student_id + academic_year_id)، لا بـ`students` وحده.

### 2.3 المنهج والتقييم

| الجدول | الأعمدة |
|---|---|
| `subjects` | id، grade_id، term_id، الاسم، طريقة التقييم (رقمي/وصفي)، الدرجة القصوى، درجة النجاح، الحصص/الأسبوع |
| `assessment_types` | id، school_id، الاسم، الترتيب، is_default، is_exam |
| `rubrics` | id، school_id، الاسم، is_default |
| `rubric_levels` ✅(5-أ) | id، rubric_id، الاسم، القيمة، الترتيب — **يلزم فورم تعريف مستويات غير موجود** |
| `assessments` | id، subject_id، الاسم، assessment_type_id، الدرجة العظمى، نسبة الوزن |
| `grades_scores` | id، assessment_id، student_id، الدرجة (nullable)، تاريخ الإدخال |
| `schedule_slots` | id، section_id، term_id، subject_id، staff_id (nullable)، اليوم، بداية، نهاية، رقم الحصة، الغرفة |

### 2.4 الحضور

| الجدول | الأعمدة |
|---|---|
| `attendance_records` ✅(3-ج، 4-أ) | id، student_id، section_id، **`date`**، **`status`** ∈ `{present, late, absent}`، **`source`** ∈ `{manual, gate}`، recorded_by، recorded_at — **قيد فريد** `(student_id, date)`؛ **لا `schedule_slot_id`** |
| `attendance_sessions` | id، section_id، التاريخ، حالة التقديم، من قدّم 🔶 |
| `absence_excuses` | id، student_id، التاريخ/النطاق، السبب، الحالة (معلّق/مقبول/مرفوض)، من راجع |
| `student_cards` ✅(16-ب) | id، student_id، **`nfc_uid`**، تاريخ الإصدار، تاريخ الإلغاء، is_active |
| `gate_scans` ✅(16-ج) | id، nfc_uid، student_id (nullable)، at، **النتيجة** (نجاح/بطاقة مجهولة/ملغاة) |

> **«غياب بعذر» مشتقّ** ✅(4-أ): `absent` + وجود `absence_excuses` مقبول لنفس (student, date). شريط الملخّص الرباعي يُحسب بهذه القاعدة، ولا يُخزَّن.

### 2.5 الرسوم

| الجدول | الأعمدة |
|---|---|
| `fee_types` | id، school_id، الاسم، grade_id (nullable = «بدون صف»)، subject_id (nullable)، is_transport، **المبلغ الإجمالي** (المصدر الوحيد ✅1-أ)، ملاحظات، is_default، الحالة |
| `fee_type_installments` | id، fee_type_id، الترتيب، تاريخ الاستحقاق، المبلغ، ملاحظات |
| `fee_plans` ✅(2-أ) | id، student_id، academic_year_id، fee_type_id (nullable للخطة المخصصة، **مرجع تاريخي فقط**)، **`total_amount`**، **`discount_amount`**، `net_amount` (محسوب)، ملاحظات، `payment_reminders`، الحالة |
| `fee_plan_installments` ✅(2-أ) | id، fee_plan_id، الترتيب، تاريخ الاستحقاق، المبلغ، ملاحظات — **منسوخة من `fee_type_installments` لحظة الإنشاء** |
| `fee_payments` | id، fee_plan_id، installment_id (nullable)، التاريخ، المبلغ، الوصف، مرجع/إيصال |

> **نسخة لا مرجع** ✅(2-أ): تعديل نوع القسط لاحقاً **لا يمسّ** الخطط القائمة. وهذا يحلّ أيضاً غياب جدول الأقساط عن بطاقة الطالب: يجب أن يُعرض من `fee_plan_installments`.

### 2.6 المنشورات والتواصل

| الجدول | الأعمدة |
|---|---|
| `post_types` | id، school_id، المفتاح، الاسم، المجموعة/اللون، الترتيب، is_enabled، أدنى دور للإنشاء، **`requires_approval`** ✅(9-أ) |
| `posts` | id، school_id، post_type_id، author_id، العنوان، النص، subject_id (nullable)، **`status`** ∈ `{draft, pending, published, rejected}` ✅(9-أ)، created_at، published_at |
| `post_targets` | post_id، النطاق (الكل/صف/شعبة/طالب/رحلة/مادة)، target_id |
| `post_approvals` ✅(9-أ) | id، post_id، reviewer_id، القرار، ملاحظة، decided_at |
| `conversations` | id، school_id، النوع (أهالي/كادر)، student_id (للأهالي)، العنوان، الحالة (مفتوحة/قيد المعالجة/تم الحل/مغلقة)، آخر تحديث |
| `conversation_participants` | conversation_id، user_id، is_muted، آخر قراءة 🔶 |
| `messages` | id، conversation_id، sender_id، النص، تاريخ الإرسال، حالة القراءة |
| `attachments` ✅(12-أ) | id، **`owner_type`** ∈ `{message, post, excuse, report_card}`، **`owner_id`**، المسار، mime، الحجم، uploaded_by، created_at — **جدول موحّد polymorphic** |

### 2.7 التقارير والإشعارات والتفضيلات

| الجدول | الأعمدة |
|---|---|
| `report_cards` | id، student_id، term_id، academic_year_id، ملاحظات المشرف، `average`، **`status`** ∈ `{draft, published}`، created_at، published_at، created_by |
| `report_card_lines` ✅(11-ج) | id، report_card_id، subject_id، الدرجة، التقدير، الترتيب — **تُكتَب لحظة النشر فقط**؛ في المسودة يُحسب الكشف حياً من `grades_scores` (يفسّر «المعدّل: –») |
| `school_notification_settings` ✅(8-أ) | id، school_id، **`app`** ∈ `{staff, guardian}`، `key`، `group`، is_enabled |
| `user_notification_settings` ✅(8-أ) | id، user_id، `key`، is_enabled |
| `notifications` | id، user_id، النوع، العنوان، النص، ref_id، is_read، created_at |
| `user_preferences` | user_id، اللغة، المظهر، سلوك حفظ المرفقات |

> **الإرسال يتطلب الاثنين** ✅(8-أ): إشعار يصل فقط إذا كان مفعّلاً على مستوى المدرسة **و** على مستوى المستخدم.

### 2.8 جداول أُلغيت بقرار

| الجدول الملغى | القرار | البديل |
|---|---|---|
| `calendar_events` | ✅ 10-أ | **عرض مجمَّع (union)** من `schedule_slots` + `holidays` + `fee_plan_installments` + `posts` (فعالية/رحلة/اجتماع/تذكير) + `assessments`. يفسّر غياب زر إضافة حدث |

| `grades.fee_amount` (عمود) | ✅ 1-أ | `fee_types.total_amount` |
| `students.section_id` (عمود) | ✅ 19-ب | `student_enrollments` |

## 3. شجرة التنقل الكاملة

```
التطبيق
├── الرئيسية (تبويب 1)
│   ├── الشريط العلوي
│   │   ├── 🔔 → الإشعارات → ⋮ → إعدادات الإشعارات (للمستخدم)
│   │   └── 📣 → المنشورات → أيقونة الموافقات → منشورات بانتظار الموافقة
│   ├── ☰ → الدرج الجانبي
│   │   ├── الحساب
│   │   ├── إعدادات الإشعارات
│   │   ├── الملفات المحمّلة
│   │   ├── المظهر  → [طبقة] اختر مظهراً
│   │   ├── اللغة   → [طبقة] اختر لغة
│   │   └── تسجيل الخروج
│   ├── نظرة عامة (6 بطاقات) → الطلاب · الكادر · الصفوف والشعب · الرسوم الدراسية · (النقل ×2)
│   └── إجراءات سريعة (6)
│       ├── إضافة طالب → إنشاء مستخدم (طالب/ولي أمر)
│       ├── إضافة كادر → إنشاء مستخدم (مشرف/معلم/سائق)
│       ├── إنشاء منشور → [طبقة] اختر نوع المنشور → ❓ شاشة الإنشاء (مفقودة)
│       ├── تسجيل الحضور
│       ├── الرسوم الدراسية → تفاصيل رسوم الطالب → إضافة دفعة ❓
│       └── مراجعة أعذار الغياب
│
├── التقويم (تبويب 2)
│   └── اختيار الشعبة → [طبقة] اختر صفاً → [طبقة] اختر شعبة
│
├── التواصل (تبويب 3)
│   ├── الأهالي → FAB → مراسلة جديدة → [طبقة] اختر طالباً
│   ├── الكادر  → FAB → محادثة جديدة → المحادثة → ⋮ → كتم الإشعارات
│   └── المحادثة
│
└── الإعدادات (تبويب 4) ── بوابة الأقسام الإدارية
    ├── إعداد المدرسة
    │   ├── إعدادات المدرسة
    │   ├── السنوات الأكاديمية
    │   ├── الصفوف والشعب → [طبقة] إضافة شعبة
    │   └── العطل والإجازات
    ├── الطلاب والكادر
    │   ├── الطلاب ⇄ أولياء الأمور → استيراد الطلاب من ملف → ❓ مطابقة الأعمدة (مفقودة)
    │   └── الكادر → إنشاء مستخدم
    ├── الشؤون الأكاديمية
    │   ├── أنواع التقييم → [طبقة] إضافة فئة
    │   ├── المقاييس الوصفية → إضافة/تعديل مقياس
    │   ├── المواد الدراسية → مادة جديدة
    │   ├── الجدول الدراسي → إضافة حصة
    │   └── إدخال الدرجات → التقييمات
    ├── الحضور والغياب
    │   ├── تسجيل الحضور
    │   ├── حضور البوابة → [طبقة] لوحة المسح
    │   ├── سجل الحضور
    │   └── أعذار الغياب
    ├── الرسوم
    │   ├── أنواع الأقساط → إضافة نوع قسط → [طبقة] اختر صفاً / اختر مادة
    │   └── الرسوم الدراسية → تعيين الرسوم
    ├── النقل ······································ خارج النطاق
    ├── المنشورات
    │   ├── إنشاء منشور → [طبقة] اختر نوع المنشور
    │   ├── عرض المنشورات → [طبقة] نطاق الاستهداف
    │   └── أنواع المنشورات (الصلاحيات)
    ├── التواصل
    │   ├── إدارة الإشعارات (تبويبا الكادر/الأهالي)
    │   └── الرسائل ······························ نفس تبويب التواصل
    ├── الوسائط → معرض الصور
    └── التقارير → كشوف الدرجات
        ├── إنشاء كشف درجات → [طبقة] صف → شعبة → طالب
        └── نشر كشف الدرجات → [حوار] تأكيد
```

**ملاحظات تنقّل:**
- الإعدادات **بوابة** لا شاشة إعدادات جهاز؛ تفضيلات الجهاز (لغة/مظهر) في **الدرج**.
- 4 شاشات لها **مدخلان**: الطلاب، الكادر، الرسوم الدراسية، تسجيل الحضور، أعذار الغياب (من الرئيسية ومن الإعدادات).
- «الرسائل» و«المنشورات» لهما مدخلان أيضاً (شريط علوي/تبويب + الإعدادات) — الشاشة واحدة والشريط العلوي يختلف.

## 4. الـ Widgets المشتركة — القائمة النهائية

كلها معرَّفة في [`00-design-system.md`](spec/00-design-system.md).

**الهيكل**
1. `AppBar` — 6 أشكال: الرئيسية · عنوان+رجوع · عنوان+فرعي · عنوان+إجراء · حوار (✕) · محادثة (أفاتار+اسم+⋮)
2. `BottomNavBar` — 4 عناصر
3. `Drawer`
4. `Tabs` (تبويبات علوية بمؤشّر)
5. `BottomSheet` — 4 تنويعات: قائمة اختيار · شبكة اختيار · نموذج · لوحة حالة/تنقّل
6. `Dialog`

## 5. عناصر القوائم — `ListItem` أساسي واحد + تنويعات

### التركيب الأساسي (RTL)

```
[قائد]  [عمود النص]                       [ذيل]
 يمين    العنوان (أساسي، عريض)             يسار
         سطر ثانوي (رقم/تاريخ/وصف)
         رقاقة وسم (اختيارية)
```

- **القائد**: أفاتار دائري بحرف · مربّع أيقونة · مقبض سحب ⠿ · لا شيء
- **الذيل**: رقاقة/رقاقتان حالة · أيقونات إجراء · ⋮ · سهم ‹ · مبدّل ثلاثي · حقل إدخال · مفتاح · مربّع اختيار

### التنويعات الست

| # | التنويعة | الفرق | مثال |
|---|---|---|---|
| 1 | **بسيط** | بلا خلفية، الفصل بالتباعد | الطلاب، الكادر، أنواع التقييم |
| 2 | **بطاقة** | داخل بطاقة بخلفية وزوايا | المقاييس، أنواع الأقساط، اختيار الصف |
| 3 | **بطاقة بشريط** | + شريط عمودي ملوّن على الحافة اليمنى | المراسلات، التقييمات، الصفوف |
| 4 | **تفصيلي** | + شبكة قيم (عمودان × صفّان) + شريط تقدّم | رسوم الطالب |
| 5 | **قابل للتوسعة** | + سهم ⌃⌄ يكشف محتوى داخلياً | الصفوف والشعب، السنة/الفصول |
| 6 | **إدخال** | الذيل حقل تفاعلي بدل عرض | إدخال الدرجات، تسجيل الحضور |

### عناصر شبكة (ليست ListItem)

- **بطاقة الشبكة**: أيقونة فوق + تسمية تحت، وسط — بوابة الإعدادات، الإجراءات السريعة، شبكة أنواع المنشور، بطاقات الاختيار.
