## الشاشات

| الاسم | وظيفتها | شو بتعرض |
|---|---|---|
| **مادة جديدة** | إنشاء مادة دراسية | بطاقة ترويسة «مادة جديدة / المواد»، ثم حقول: المادة، الصف، الفصل الدراسي، طريقة التقييم، الدرجة القصوى، درجة النجاح، الحصص في الأسبوع (عدّاد). زر حفظ **معطّل** حتى تكتمل الحقول الإلزامية |
| **اختر صفاً** (طبقة سفلية) | اختيار الصف | عنوان «اختر صفاً» + قائمة الصفوف (الاسم + «<n> شعب» + سهم). تُستدعى من عدّة شاشات |
| **الجدول الدراسي** | عرض حصص شعبة حسب اليوم | بطاقة الشعبة (الاسم + «<n> حصة» + زر تبديل)، شريط أيام أفقي (الأحد→الخميس)، ثم قائمة الحصص. FAB إضافة |
| **إضافة حصة** | جدولة حصة | بطاقة الشعبة (للقراءة)، الفصل الدراسي، المادة، معلم (اختياري) مع تنبيه إسناد، اليوم، وقت البداية/النهاية، رقم الحصة، الغرفة (اختياري)، زرَا حفظ وإلغاء |
| **إدخال الدرجات — بلا تقييمات** | حالة أولية | تنبيه «لا توجد تقييمات بعد» + رابط «+ إنشاء تقييم»، وتحته حالة فارغة «اختر تقييماً» |
| **إدخال الدرجات** | إدخال درجات طلاب مادة | مُنتقي التقييم، بطاقة تقدّم (عدد الطلاب + مُدخَل/الكل)، قائمة الطلاب مع حقل درجة لكل طالب، شريط ملخّص سفلي (تم تقييمه / غير مقيّم / المعدل)، زر «حفظ الدرجات» |
| **التقييمات** | إدارة تقييمات مادة | قائمة التقييمات كبطاقات بشريط جانبي ملوّن: الاسم، رقاقة الفئة، الدرجة العظمى، نسبة الوزن، قائمة إجراءات. FAB إضافة |

## الحقول

### فورم: مادة جديدة

| الحقل | نوعه | إلزامي |
|---|---|---|
| المادة | نص، أيقونة كتاب | **نعم** — معلّم بنجمة `*` |
| الصف | قائمة منسدلة («اختر صفاً») | **لا** — بلا نجمة |
| الفصل الدراسي | قائمة منسدلة، افتراضي «الفصل الأول» | **نعم** — معلّم بنجمة `*` |
| طريقة التقييم | مبدّل ثنائي (رقمي / وصفي)، افتراضي «رقمي» | لا — له قيمة افتراضية |
| الدرجة القصوى | رقم، قيمة مسبقة 100 | غير واضح — بلا نجمة |
| درجة النجاح | رقم، قيمة مسبقة 50 | غير واضح — بلا نجمة |
| الحصص في الأسبوع | عدّاد (− / +)، قيمة مسبقة 3 | لا — له قيمة افتراضية |

> زر «حفظ» يظهر **معطّلاً** طالما لم تُملأ الحقول الإلزامية — أول تحقّق مرئي في العيّنة كلها.
> «الصف» بلا نجمة رغم أن قائمة المواد مفلترة بالصف دائماً — **تناقض محتمل**.

### فورم: إضافة حصة

| الحقل | نوعه | إلزامي |
|---|---|---|
| الشعبة | بطاقة للقراءة فقط (تأتي من سياق الجدول) | — ليست حقلاً |
| الفصل الدراسي | قائمة منسدلة، افتراضي «الفصل الأول» | غير واضح — بلا نجمة |
| المادة | قائمة منسدلة («اختر مادة») | غير واضح — لكنها **شرط** لتفعيل حقل المعلم |
| معلم | قائمة منسدلة، موسوم «(اختياري)» | **لا** |
| اليوم | رقاقات أيام (الأحد → الخميس)، افتراضي «الأحد» | لا — له قيمة افتراضية |
| وقت البداية | مُنتقي وقت، قيمة مسبقة 08:00 | غير واضح |
| وقت النهاية | مُنتقي وقت، قيمة مسبقة 08:45 | غير واضح |
| الحصة # | قائمة منسدلة، قيمة مسبقة 1 | غير واضح |
| الغرفة | نص، موسوم «(اختياري)» | **لا** |

سلوكان خاصّان:
- قبل اختيار المادة يُستبدل حقل المعلم بتنبيه برتقالي **«اختر المادة أولاً»**.
- عند اختيار معلم غير مسند للمادة تظهر بجانب اسمه «(غير مسند)» بالبرتقالي، وتحته تنبيه «هذا المعلم غير مسند للمادة المختارة» مع زر **«إسناد لهذه المادة»** — أي أن الإسناد يمكن إنشاؤه من هنا.

### فورم: إدخال الدرجات

| الحقل | نوعه | إلزامي |
|---|---|---|
| التقييم | قائمة منسدلة، تعرض «<اسم التقييم> (<الدرجة العظمى>)» | نعم — لا تظهر القائمة بدونه |
| درجة كل طالب | رقم داخل الحقل، لاحقة «/100» ثابتة، فارغ يظهر كـ «–» | لا — يمكن الحفظ جزئياً (2/11) |

> حقل الدرجة النشط يأخذ إطار Primary؛ والفارغ خلفية داكنة بلا إطار.

### فورمات غير مرصودة

- **إنشاء/تعديل تقييم** — الـ FAB ورابط «+ إنشاء تقييم» موجودان، والشاشة غير ملتقطة. الحقول المتوقّعة من بطاقة التقييم: الاسم، الفئة، الدرجة العظمى، نسبة الوزن.
- **تعديل مادة** و**تعديل حصة** — عبر ⋮ أو النقر، غير مرصودة.

## القوائم

### قائمة الحصص (الجدول الدراسي)

فارغة في اللقطة. الفلترة: **شعبة + يوم** معاً (بطاقة الشعبة + شريط الأيام)، بلا بحث ولا ترقيم.

### قائمة طلاب إدخال الدرجات

البيانات الظاهرة بكل عنصر:
- أفاتار دائري بحرف واحد
- اسم الطالب
- رقمه (42، 39، 37، 36)
- حقل درجة على اليسار بلاحقة «/<الدرجة العظمى>»

الفلترة: مادة (من سياق الدخول) + تقييم (من المُنتقي). لا بحث ولا ترقيم.
شريط ملخّص سفلي ثابت: **تم تقييمه** / **غير مقيّم** / **المعدل** — يتحدّث فورياً مع الإدخال (0 · 11 · – ثم 2 · 9 · 37.5).

> المعدل 37.5 = متوسط المُدخَل فقط ((10+65)/2)، لا متوسط كل الطلاب.

### قائمة التقييمات

البيانات الظاهرة بكل عنصر (بطاقة بشريط عمودي Primary على الحافة اليمنى):
- اسم التقييم («ممتاز»)
- رقاقة الفئة («مستمر») — مرّتان بلونين مختلفين: رقاقة Primary ورقاقة رمادية
- رقاقة الدرجة العظمى («100»)
- رقاقة النسبة البرتقالية («100%») — الوزن
- زر قائمة إضافية (⋮)

بحث/فلتر/ترقيم: لا شيء. القائمة في سياق مادة محدّدة.

> بنية العنصر **غير واضحة**: يظهر سطران برقاقتَي «مستمر» بلونين — قد يكون أحدهما الفئة والآخر نوع الاحتساب، أو خطأ عرض.

## الأزرار

| الشاشة | الزر | شو بيعمل |
|---|---|---|
| مادة جديدة | مبدّل رقمي/وصفي | يبدّل طريقة التقييم |
| مادة جديدة | + / − في الحصص بالأسبوع | يزيد/ينقص العدد |
| مادة جديدة | حفظ (أساسي، **معطّل** ابتداءً) | ينشئ المادة |
| اختر صفاً | صف من القائمة | يختار الصف ويغلق الطبقة |
| الجدول الدراسي | زر تبديل الشعبة (سهمان) على بطاقة الشعبة | يفتح اختيار شعبة أخرى |
| الجدول الدراسي | رقاقات الأيام | تبدّل اليوم المعروض |
| الجدول الدراسي | FAB (+) بلون Primary | يفتح «إضافة حصة» |
| إضافة حصة | إسناد لهذه المادة (أساسي، داخل التنبيه) | يسند المعلم المختار للمادة |
| إضافة حصة | رقاقات الأيام | تختار يوم الحصة |
| إضافة حصة | مُنتقيا الوقت | يفتحان منتقي الوقت |
| إضافة حصة | حفظ (أساسي) | يجدول الحصة |
| إضافة حصة | إلغاء (نصّي) | يغلق بلا حفظ |
| إضافة حصة | ✕ في الشريط العلوي | يغلق الشاشة |
| إدخال الدرجات | + إنشاء تقييم (نصّي، داخل التنبيه) | يفتح إنشاء تقييم للمادة |
| إدخال الدرجات | مُنتقي التقييم | يبدّل التقييم المعروض |
| إدخال الدرجات | حفظ الدرجات (أساسي، أيقونة قرص) | يحفظ الدرجات المُدخلة |
| التقييمات | FAB (+) بلون Primary | إنشاء تقييم |
| التقييمات | ⋮ على التقييم | قائمة إجراءات — **المحتوى غير مرصود** |
| كل الشاشات | سهم الرجوع (←) | رجوع |

## المكوّنات المشتركة

من [`00-design-system.md`](00-design-system.md):

- الشريط العلوي — «عنوان + رجوع»، «عنوان + عنوان فرعي» (إدخال الدرجات: العنوان + اسم المادة)، «نمط الحوار (✕)».
- بطاقة الترويسة داخل القسم؛ بطاقة الإحصائية (الممتلئة والخافتة).
- حقل النص، حقل الاختيار (Selector)، حقل العدّاد (Stepper).
- علامة الحقل الإلزامي (`*`).
- التنبيه داخل المحتوى (Inline alert) — بثلاث حالات: بلا تقييمات، اختر المادة أولاً، معلم غير مسند.
- المبدّل الشريطي الثنائي (رقمي/وصفي).
- الرقاقات: فلتر مفعّل/غير مفعّل (الأيام)، وسم، رقاقة رقمية.
- عنصر القائمة — التنويعة الأساسية وتنويعة «بطاقة» بشريط عمودي ملوّن.
- شريط الملخّص السفلي (ثلاثة أعمدة).
- الأزرار: أساسي ممتلئ، أساسي معطّل، نصّي؛ زر الإجراء العائم (FAB) — Primary في كل شاشات هذا الجزء.
- الطبقة السفلية — تنويعة قائمة الاختيار.
- الحالة الفارغة.

## قوائم فارغة

| القائمة | شو المتوقع تعرضه |
|---|---|
| **حصص اليوم (الجدول الدراسي)** | حالة فارغة: أيقونة مفكّرة، عنوان «لا توجد حصص مجدولة»، سطر ثانوي «إضافة حصة». الإجراء عبر الـ FAB |
| **إدخال الدرجات — بلا تقييم مختار** | حالة فارغة: أيقونة قائمة بعلامة ✓، عنوان «اختر تقييماً»، سطر ثانوي «اختر تقييماً لإدخال الدرجات» — تظهر **فوقها** بطاقة تنبيه «لا توجد تقييمات بعد» مع رابط الإنشاء |
| **التقييمات** | غير مرصودة |
| **طلاب الشعبة في إدخال الدرجات** | غير مرصودة |

> ملاحظة: شاشة إدخال الدرجات تعرض **تنبيهاً وحالة فارغة معاً** — نمط مزدوج لم يتكرّر في أي شاشة أخرى.

## غير واضح

1. **«الصف» بلا نجمة** في فورم المادة رغم أن كل عرض للمواد مفلتر بالصف.
2. **شروط تفعيل زر الحفظ** بدقّة — أي حقول يفحصها.
3. **بنية عنصر التقييم** — رقاقتا «مستمر» بلونين مختلفين في نفس البطاقة.
4. **مصدر «ممتاز» كاسم تقييم** — هل هو اسم حرّ أم مستوى من مقياس وصفي (يتقاطع مع بند مستويات المقياس في [`03c1-academic.md`](03c1-academic.md)).
5. **نسبة الوزن 100%** — هل مجموع أوزان تقييمات المادة يجب أن يساوي 100؟ لا تحقّق ظاهر.
6. **العلاقة بين `teacher_subjects` و`teacher_sections`** — هل الإسناد للمادة أم للمادة داخل شعبة معيّنة.
7. **تعارض الحصص** — لا تحقّق ظاهر لتضارب وقت المعلم أو الغرفة.
8. **مصدر قائمة «الحصة #»** — ثابتة أم من إعداد.
9. **هل الأيام خمسة دائماً** (الأحد→الخميس) أم قابلة للإعداد.
10. **طريقة إدخال الدرجة للمواد الوصفية** — كل اللقطات لمادة «رقمي».
11. **سلوك الحفظ الجزئي** — هل يُحفظ الفارغ كـ null أم يُتجاهل.
12. **حدود عدّاد الحصص في الأسبوع** (أدنى/أقصى).
13. **محتوى قوائم ⋮** للمادة والحصة والتقييم.
14. **«الدرجة القصوى» على المادة مقابل «الدرجة العظمى» على التقييم** — أيهما يحكم حقل الإدخال (اللقطة تُظهر /100 من التقييم) — **تناقض محتمل**.
