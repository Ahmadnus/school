# الرئيسية

المصدر: `docs/screens/home/` (6 مجلدات فرعية، 33 صورة) و`docs/screens/home-light.jpg` / `home-dark.jpg`.
الألوان والمقاسات مرجعها [`00-design-system.md`](00-design-system.md).

> **ملاحظة على المصدر**: معظم شاشات هذه المجلدات هي **نفس شاشات قسم الإعدادات** بثيم **light**، مبلوغة من الرئيسية مباشرة. وثّقت هنا ما هو خاص بالرئيسية وما يضيف جديداً، وأشرت لمواضع التوثيق الأصلية.
> ثلاث شاشات في هذه المجلدات **تسدّ فجوات** كانت مفتوحة في ملفات الإعدادات: إنشاء طالب/ولي أمر، وتفاصيل رسوم الطالب مع تسجيل الدفعات، وشاشة تعيين الرسوم.

## الحقول

### فورم: إنشاء مستخدم (طالب)

**قسم النوع**

| الحقل | نوعه | إلزامي |
|---|---|---|
| النوع | بطاقتا اختيار: طالب / ولي أمر | نعم — «طالب» افتراضياً |

**قسم الاسم**

| الحقل | نوعه | إلزامي |
|---|---|---|
| الاسم الأول | نص | غير واضح — بلا نجمة |
| الاسم الأخير | نص | غير واضح |
| معرّف خاص (اختياري) | نص، أيقونة بصمة | **لا** — مصرّح نصّاً |

**قسم التسجيل**

| الحقل | نوعه | إلزامي |
|---|---|---|
| نطاق التسجيل | رقاقات اختيار: **سنة كاملة** (مختارة ✓) / الفصل الأول / الفصل الثاني | نعم — لها قيمة افتراضية |

**قسم الصف / الشعبة (اختياري)**

| الحقل | نوعه | إلزامي |
|---|---|---|
| الصف | قائمة منسدلة | **لا** — العنوان يصرّح «(اختياري)» |
| الشعبة | قائمة منسدلة | لا |

**قسم النقل**

| الحقل | نوعه | إلزامي |
|---|---|---|
| الاشتراك في النقل | **مربّع اختيار (Checkbox)** | لا — **خارج النطاق تفصيلاً** |

**قسم الرسوم**

| الحقل | نوعه | إلزامي |
|---|---|---|
| نوع القسط | يُختار عبر طبقة «اختر نوع القسط» | لا — تنبيه: «لم يتم اختيار أي نوع قسط – لن يتم إنشاء خطة رسوم» |

**قسم البيانات الشخصية**

| الحقل | نوعه | إلزامي |
|---|---|---|
| تاريخ التسجيل | مُنتقي تاريخ، مملوء باليوم | نعم — له قيمة |
| تاريخ الميلاد | مُنتقي تاريخ («اختر تاريخاً») | غير واضح |
| الجنس | بطاقتا اختيار: ذكر / أنثى — **بلا اختيار افتراضي** | غير واضح |
| الجنسية | نص | غير واضح |
| فصيلة الدم | نص | غير واضح |
| العنوان | نص متعدد الأسطر | غير واضح |
| اسم المبنى أو الفرع | نص | غير واضح |
| ملاحظات طبية | نص متعدد الأسطر | غير واضح |

**قسم ولي الأمر (اختياري) — صفوف متكرّرة**

لكل ولي أمر بطاقة «ولي أمر <n>» بأيقونة حذف حمراء:

| الحقل | نوعه | إلزامي |
|---|---|---|
| الوضع | مبدّل: **ربط ولي أمر موجود** (مختار) / إنشاء جديد | نعم |
| بحث عن ولي أمر | حقل بحث بسهم جانبي (في وضع الربط) | نعم في وضع الربط |
| صلة القرابة | ثلاث بطاقات اختيار: الأب / الأم / الوصي — **بلا اختيار افتراضي** | غير واضح |
| جهة الاتصال الرئيسية | مفتاح (Switch)، مطفأ | لا |

- أسفل البطاقة زر «+ إضافة ولي أمر آخر».
- في وضع **«إنشاء جديد»** يُتوقّع ظهور حقول ولي أمر — **غير ملتقطة**.

### فورم: تعيين الرسوم

| الحقل | نوعه | إلزامي |
|---|---|---|
| الطالب | حقل اختيار بأيقونة بحث عن شخص | **نعم** — التنبيه يقول «يرجى ملء جميع الحقول» |
| السنة الأكاديمية | للقراءة فقط (2026-2027) بأيقونة **قفل** | — مقفلة |
| المبلغ الإجمالي | رقم، أيقونة `$` | نعم |
| مبلغ الخصم | رقم، أيقونة وسم | غير واضح |
| المبلغ الصافي | **محسوب** (شريط بلون Primary) — لا يُدخَل | — |
| جدول الأقساط | صفوف متكرّرة: تاريخ القسط، المبلغ، ملاحظات (اختياري) + «+ إضافة دفعة» + «المجموع: 0 من 0» | غير واضح |
| ملاحظات | نص متعدد الأسطر | لا |

> هذا الفورم يحلّ سؤال «أين يُدخَل الخصم؟» المفتوح في [`03e2-fees.md`](03e2-fees.md).
> أيقونة `$` على حقل مبلغ بينما العملة المعروضة «ل.س» — **عدم اتساق**.

### فورم: إضافة دفعة

الزر موجود في شاشة تفاصيل رسوم الطالب، والفورم نفسه **غير ملتقط**.
الحقول المتوقّعة من سجل المدفوعات: التاريخ، المبلغ، وصف الدفعة («دفعة أولى»).

### فورم: الملفات المحمّلة

| الحقل | نوعه | إلزامي |
|---|---|---|
| حفظ المرفقات | إعداد بقيمة «السؤال عند كل ملف» وزر «تغيير» | له قيمة افتراضية |

## القوائم

### شبكة «نظرة عامة» (بطاقات الإحصائيات)

6 بطاقات في شبكة 3×2، كل بطاقة: رقم كبير ملوّن + رسم توضيحي + تسمية + سهم انتقال.

| البطاقة | القيمة | لون الرقم |
|---|---|---|
| الطلاب | 39 | تركوازي |
| الكادر | 14 | تركوازي |
| الشعب | 4 | كحلي |
| رسوم مستحقة | 39 | أحمر |
| الحافلات | 0 | برتقالي |
| الرحلات | 0 | برتقالي |

> تسميتا «رسوم مـ…» و«الرحلات …» **مقتطعتان** في العرض.
> «رسوم مستحقة 39» = عدد الطلاب لا مبلغ — **مضلّل**؛ ونفس الرقم يساوي عدد الطلاب الكلي.

بحث/فلتر/ترقيم: لا شيء — شبكة ثابتة.

### شبكة «إجراءات سريعة»

6 إجراءات في شبكة 3×2، كل إجراء: أيقونة ملوّنة كبيرة + تسمية بسطر أو سطرين، بلا خلفية بطاقة:
إضافة طالب · إضافة كادر · إنشاء منشور · تسجيل الحضور · الرسوم الدراسية · مراجعة أعذار الغياب.

### قائمة الدرج الجانبي

- الحساب (أيقونة شخص)
- إعدادات الإشعارات (جرس)
- الملفات المحمّلة (سهم تحميل)
- المظهر: <القيمة> — القيمة بلون Primary
- اللغة: <القيمة> — القيمة بلون Primary
- تسجيل الخروج (أحمر، مفصول بخط في الأسفل)

### قائمة «المعلومات الشخصية» (شاشة الحساب)

صفوف بطاقات للقراءة فقط: مربّع أيقونة + تسمية صغيرة + القيمة تحتها.
الحقول: الاسم الأول، الاسم الأخير، البريد الإلكتروني («–» عند الفراغ)، الهاتف، الدور، الحالة (نقطة ملوّنة + «نشط»).
**لا يوجد زر تعديل** في هذه الشاشة.

### سجل المدفوعات (تفاصيل رسوم الطالب)

كل عنصر: مربّع أيقونة نقود + التاريخ (2026-09-03) + وصف الدفعة («دفعة أولى») + المبلغ بلون Primary + **أيقونة تحميل** (إيصال؟).

### قائمة «اختر نوع القسط» (طبقة سفلية)

مجمّعة بعنوان «حسب الصف». كل بطاقة: اسم القسط + رقاقة الصف + المبلغ.
أسفل القائمة خيار **«خطة مخصصة»** بأيقونة مُعدِّلات.

## الأزرار

| الشاشة | الزر | شو بيعمل |
|---|---|---|
| الرئيسية | أيقونة الجرس | الإشعارات — **الشاشة غير ملتقطة** |
| الرئيسية | أيقونة مكبّر الصوت | الإعلانات/المنشورات — **الوجهة غير مؤكّدة** |
| الرئيسية | ☰ في بطاقة الترويسة | يفتح الدرج الجانبي |
| الرئيسية | أي بطاقة إحصائية | تنتقل لشاشة القسم (انظر جدول الوجهات) |
| الرئيسية | أي إجراء سريع | ينتقل للشاشة أو يفتح الطبقة المناسبة |
| الرئيسية | عناصر شريط التنقل الأربعة | الرئيسية / التقويم / التواصل / الإعدادات |
| الدرج | تسجيل الخروج | يخرج من الحساب — **بلا حوار تأكيد مرصود** |
| الدرج | المظهر / اللغة | يفتحان طبقة اختيار |
| الملفات المحمّلة | تغيير | يبدّل سلوك حفظ المرفقات |
| إنشاء طالب | بطاقتا طالب / ولي أمر | تبدّلان نوع المستخدم |
| إنشاء طالب | + إضافة ولي أمر / + إضافة ولي أمر آخر | يضيف بطاقة ولي أمر |
| إنشاء طالب | حفظ (أساسي، ✓) | ينشئ الطالب |
| تفاصيل الرسوم | **إضافة دفعة** (كبسولة بيضاء داخل بطاقة Primary) | يفتح فورم تسجيل دفعة — **غير ملتقط** |
| تفاصيل الرسوم | مفتاح «التنبيهات» | يفعّل تذكيرات الدفع لهذا القسط |
| تفاصيل الرسوم | أيقونة التحميل على الدفعة | تحميل إيصال؟ — **غير مؤكّد** |
| تفاصيل الرسوم | ⋮ في الشريط العلوي | قائمة إجراءات — **المحتوى غير مرصود** |
| تعيين الرسوم | تعيين الرسوم (أساسي) | ينشئ خطة الرسوم |
| اختر نوع القسط | خطة مخصصة | ينتقل لـ«تعيين الرسوم» بمبالغ حرّة — **مفترض** |

## المكوّنات المشتركة

من [`00-design-system.md`](00-design-system.md):

- الشريط العلوي — شكل الرئيسية، وشكل «عنوان + رجوع»، و«نمط الحوار (✕)»، و«عنوان + عنوان فرعي».
- بطاقة الترويسة (hero) بالتدرّج؛ بطاقات الإحصائيات؛ الإجراءات السريعة؛ شريط التنقل السفلي.
- حقل النص، حقل البحث، حقل الاختيار، مُنتقي التاريخ.
- **مربّع الاختيار (Checkbox)** — أول ظهور؛ أضفتُه للمرجع.
- المفتاح (Switch)؛ بطاقة الاختيار؛ رقاقات الاختيار بعلامة ✓.
- بطاقة تجميع الحقول — تنويعة الصفوف المتكرّرة (ولي أمر <n>، القسط <n>).
- التنبيه داخل المحتوى (Inline alert).
- الطبقة السفلية — تنويعتا قائمة الاختيار وشبكة الاختيار.
- عنصر القائمة؛ شريط التقدّم؛ الحالة الفارغة؛ الأزرار؛ FAB.

مكوّن جديد:

- **الدرج الجانبي (Drawer)**: لوحة تغطي ~85% من عرض الشاشة من اليمين (RTL)، ترويسة مربّعة بلون Primary تحمل أفاتاراً كبيراً واسم المستخدم، ثم صفوف تنقّل (أيقونة + نص)، وفي الأسفل صف مفصول بخط للخروج بلون أحمر. المحتوى خلفها معتّم.

## غير واضح

1. **«رسوم مستحقة 39»** — عدد لا مبلغ، ويساوي عدد الطلاب الكلي؛ تسمية مضلّلة أو بيانات اختبار.
2. **وجهة زر مكبّر الصوت** في الشريط العلوي.
3. **شاشة الإشعارات** (زر الجرس) غير ملتقطة إطلاقاً.
4. **فورم إضافة دفعة** غير ملتقط — رغم أن الزر موجود.
5. **دلالة أيقونة التحميل** على عنصر الدفعة (إيصال PDF؟).
6. **«خطة مخصصة»** — ما الفرق عن اختيار نوع قسط، وهل تتيح مبالغ حرّة.
7. **إنشاء مستخدم (ولي أمر)** — حقوله غير ملتقطة.
8. **وضع «إنشاء جديد»** لولي الأمر داخل فورم الطالب — حقوله غير ملتقطة.
9. **لا حوار تأكيد لتسجيل الخروج** في اللقطات.
10. **لا زر تعديل في شاشة الحساب** — كيف يعدّل المستخدم بياناته؟
11. **أيقونة `$`** على حقل المبلغ مع عملة «ل.س».
12. **السنة الأكاديمية مقفلة** في تعيين الرسوم — هل يمكن تعيين رسوم لسنة أخرى؟
13. **تكرار مسارين لخطة الرسوم**: «تعيين الرسوم» من شاشة الرسوم، و«اختر نوع القسط» من فورم الطالب — هل ينتجان نفس السجل؟ **تناقض محتمل**.
14. **بطاقة «الشعب» تفتح شاشة الصفوف والشعب** لا شاشة شعب — التسمية لا تطابق الوجهة.
15. **«معرّف خاص»** — لأي غرض؟ رقم وطني؟ باركود؟ علاقته بـ«رقم الطالب» ([`03i2-reports.md`](03i2-reports.md)) غير واضحة.
16. **الجنس وصلة القرابة بلا اختيار افتراضي** بينما نطاق التسجيل له افتراضي — عدم اتساق.
