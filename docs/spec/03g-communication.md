## الشاشات

| الاسم | وظيفتها | شو بتعرض |
|---|---|---|
| **إدارة الإشعارات — تطبيق الكادر** | ضبط إشعارات تطبيق الكادر | تبويبان علويان، سطر شرح «تفعيل أو تعطيل الإشعارات لكامل المدرسة»، مفتاح عام «تفعيل كل الإشعارات»، ثم مجموعات مفاتيح بعناوين: الأعذار، المعلمون، الحساب… |
| **إدارة الإشعارات — تطبيق الأهالي** | ضبط إشعارات تطبيق الأهالي | نفس التخطيط بمجموعات مختلفة: الحضور، الدرجات، بطاقات التقارير، الأعذار، الرسوم… |
| **الرسائل — تبويب الأهالي** | محادثات مع أولياء الأمور | تبويبان (الأهالي / الكادر)، بحث، رقاقات فلترة حالة، ثم قائمة المراسلات. FAB إنشاء (Primary) |
| **الرسائل — تبويب الكادر** | محادثات مع الكادر | قائمة جهات الكادر مباشرة، **بلا بحث ولا فلاتر**. FAB إنشاء (برتقالي، أيقونة قلم) |
| **مراسلة جديدة** | إرسال مراسلة لولي أمر | اختيار طالب، عنوان المراسلة، نص الرسالة، إضافة مرفق، زر إرسال (معطّل ابتداءً) |
| **المحادثة** | تبادل الرسائل مع جهة | شريط علوي بأفاتار الجهة واسمها + ⋮، مساحة الرسائل، شريط إدخال سفلي (مرفق + نص + إرسال) |

## الحقول

### فورم: إدارة الإشعارات (لكل تبويب)

| الحقل | نوعه | إلزامي |
|---|---|---|
| تفعيل كل الإشعارات | مفتاح (Switch) رئيسي، **مطفأ** في اللقطتين | لا |
| كل إشعار فرعي | مفتاح (Switch) داخل مجموعته | لا |

**مفاتيح تبويب الكادر المرصودة:**

| المجموعة | المفاتيح | الحالة |
|---|---|---|
| الأعذار | تقديم عذر، مراجعة عذر | مفعّلان |
| المعلمون | إسناد معلم | مطفأ |
| الحساب | حساب بانتظار الموافقة، الموافقة على الحساب، إسناد دور، إزالة دور | كلها مطفأة |

**مفاتيح تبويب الأهالي المرصودة:**

| المجموعة | المفاتيح | الحالة |
|---|---|---|
| الحضور | تسجيل غياب | مطفأ |
| الدرجات | إدخال درجة | مفعّل |
| بطاقات التقارير | نشر بطاقة تقرير | مفعّل |
| الأعذار | مراجعة عذر | مفعّل |
| الرسوم | (مقتطعة — غير مرصودة) | — |

> **تناقض ظاهر**: المفتاح العام «تفعيل كل الإشعارات» مطفأ بينما مفاتيح فرعية مفعّلة — العلاقة بينهما غير موضّحة (هل العام مجرّد اختصار، أم قاطع يعلو الفرعي؟).

### فورم: مراسلة جديدة

| الحقل | نوعه | إلزامي |
|---|---|---|
| اختر طالباً | صف اختيار بسهم جانبي، أيقونة تخرّج | **نعم** — على الأرجح؛ زر الإرسال معطّل ابتداءً |
| عنوان المراسلة | نص سطري | غير واضح |
| اكتب رسالتك… | نص متعدد الأسطر (~4 أسطر) | غير واضح |
| مرفق | زر «إضافة مرفق» نصّي بأيقونة مشبك | لا |

### فورم: شريط إدخال المحادثة

| الحقل | نوعه | إلزامي |
|---|---|---|
| اكتب رسالة | نص سطري | نعم للإرسال |
| مرفق | أيقونة مشبك | لا |

## القوائم

### قائمة المراسلات (تبويب الأهالي)

البيانات الظاهرة بكل عنصر (بطاقة بشريط عمودي Primary على الحافة اليمنى):
- رقاقة حالة («قيد المعالجة» برتقالية)
- زر «…» (قائمة إضافية)
- «الطالب: <اسم الطالب>» مع أيقونة تخرّج
- مقتطع من آخر رسالة («مرحباً»)
- «منذ <n> أيام»
- نقطة تركوازية = غير مقروء

بحث/فلتر/ترقيم:
- **بحث**: «ابحث باسم الطالب أو ولي الأمر»
- **فلاتر**: رقاقات اختيار — الكل / **مفتوحة أو قيد المعالجة** (مختارة بعلامة ✓) / تم الحل أو مغلقة
- **ترقيم**: لا يوجد

### قائمة جهات الكادر (تبويب الكادر)

- أفاتار دائري بحرف واحد
- اسم عضو الكادر مع تخصّصه («أ. أحمد عمر لغة عربية»)

بحث/فلتر/ترقيم: **لا شيء إطلاقاً** — لا بحث ولا فلاتر، خلافاً لتبويب الأهالي.

### قائمة رسائل المحادثة

فارغة في اللقطة — شكل فقاعة الرسالة **غير مرصود**.

## الأزرار

| الشاشة | الزر | شو بيعمل |
|---|---|---|
| إدارة الإشعارات | التبويبان | يبدّلان بين إشعارات تطبيق الكادر وتطبيق الأهالي |
| إدارة الإشعارات | مفتاح «تفعيل كل الإشعارات» | يفعّل/يعطّل الإشعارات لكامل المدرسة |
| إدارة الإشعارات | كل مفتاح فرعي | يفعّل/يعطّل نوع إشعار بعينه |
| الرسائل | التبويبان (الأهالي / الكادر) | يبدّلان القائمة |
| الرسائل — الأهالي | رقاقات الحالة | تفلتر المراسلات |
| الرسائل — الأهالي | «…» على المراسلة | قائمة إجراءات (تغيير الحالة؟) — **المحتوى غير مرصود** |
| الرسائل — الأهالي | FAB (تعليق بعلامة +) بلون Primary | يفتح «مراسلة جديدة» |
| الرسائل — الكادر | FAB (قلم) برتقالي | يفتح محادثة جديدة مع عضو كادر — **الشاشة غير ملتقطة** |
| مراسلة جديدة | صف «اختر طالباً» | يفتح اختيار طالب |
| مراسلة جديدة | إضافة مرفق (نصّي) | يفتح منتقي ملفات |
| مراسلة جديدة | إرسال (**معطّل** ابتداءً) | يرسل المراسلة |
| المحادثة | أيقونة المشبك | إرفاق ملف |
| المحادثة | زر الإرسال (مربّع Primary) | يرسل الرسالة |
| المحادثة | ⋮ في الشريط العلوي | قائمة إجراءات المحادثة — **المحتوى غير مرصود** |
| كل الشاشات | سهم الرجوع (←) | رجوع |

> **الـ FAB يختلف لوناً وأيقونةً بين تبويبَي نفس الشاشة** (Primary + تعليق للأهالي، برتقالي + قلم للكادر) — يعزّز أن معيار لون الـ FAB غير منضبط.

## المكوّنات المشتركة

من [`00-design-system.md`](00-design-system.md):

- الشريط العلوي — «عنوان + رجوع»، وتنويعة **محادثة** (أفاتار + اسم + ⋮).
- **التبويبات العلوية (Tabs)**: نصّان بعرض متساوٍ، المفعّل بلون Primary مع مؤشّر سفلي بلون Primary، وخط فاصل رفيع أسفل الشريط. مكوّن جديد — أضفتُه للمرجع.
- المفتاح (Switch) — بحالتيه.
- حقل البحث؛ حقل النص (سطري ومتعدد الأسطر)؛ حقل الاختيار (Selector).
- الرقاقات: اختيار (choice) بعلامة ✓، حالة.
- عنصر القائمة — التنويعة الأساسية وتنويعة «بطاقة» بشريط عمودي ملوّن.
- بطاقة تجميع الحقول.
- الأزرار: أساسي ممتلئ، أساسي معطّل، نصّي، أيقونة، قائمة إضافية.
- زر الإجراء العائم (FAB).
- الحالة الفارغة.

مكوّن جديد:

- **شريط إدخال الرسالة**: شريط ثابت أسفل الشاشة بخلفية أفتح: أيقونة مشبك على اليمين، حقل نص كبسولي في الوسط، ومربّع إرسال بلون Primary على اليسار.

## جداول الداتابيز المتوقعة

| الجدول | الحقول المستنتجة |
|---|---|
| `notification_settings` | id، school_id، التطبيق (كادر/أهالي)، مفتاح الإشعار، المجموعة، is_enabled |
| — أو — `notification_types` + `school_notification_prefs` | فصل التعريف عن التفضيل؛ **البنية الفعلية غير محدّدة** |
| `conversations` (المراسلات) | id، school_id، النوع (أهالي/كادر)، student_id (للأهالي)، guardian_id أو staff_id، العنوان، الحالة (مفتوحة/قيد المعالجة/تم الحل/مغلقة)، آخر تحديث |
| `messages` | id، conversation_id، sender_id، النص، تاريخ الإرسال، حالة القراءة |
| `message_attachments` | id، message_id، المسار، النوع، الحجم |

- «منذ 1 أيام» و«غير مقروء» محسوبان.
- الإرسال الفعلي (push/SMS) **خارج النطاق** — الجداول أعلاه تخزّن الإعداد والمحتوى فقط.

## غير واضح

1. **علاقة المفتاح العام بالمفاتيح الفرعية** — مطفأ عام مع فرعي مفعّل في نفس اللقطة.
2. **قائمة المفاتيح كاملة** — مجموعتا «الحساب» و«الرسوم» مقتطعتان في اللقطات.
3. **هل الإعداد على مستوى المدرسة فقط** أم لكل مستخدم أيضاً — النص يقول «لكامل المدرسة».
4. **دورة حياة حالة المراسلة** (مفتوحة → قيد المعالجة → تم الحل → مغلقة) ومن يغيّرها.
5. **محتوى قائمة «…»** على المراسلة و⋮ في المحادثة.
6. **شاشة محادثة كادر جديدة** غير ملتقطة.
7. **شكل فقاعة الرسالة** (وارد/صادر، الوقت، حالة القراءة) غير مرصود.
8. **لماذا لا بحث في تبويب الكادر** رغم أن الكادر 14 عضواً وقد يكبر.
9. **علاقة «العنوان» في المراسلة الجديدة** بالمحادثة — هل هي موضوع (ticket) أم رسالة أولى.
10. **من يبدأ المراسلة** — هل يمكن لولي الأمر البدء من تطبيق الأهالي (خارج المواصفة).
11. **أنواع وحدود المرفقات**.
12. **«المشرف العام»** يظهر في صلاحيات المنشورات ([`03f-publications.md`](03f-publications.md)) ولا يظهر هنا في جهات الكادر — يتكرّر سؤال بنية الأدوار.
13. **الرقاقة الرابعة المقتطعة** في فلاتر المراسلات (يمين الشاشة) — على الأرجح جزء من «تم الحل أو مغلقة».
