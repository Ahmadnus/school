## الشاشات

| الاسم | وظيفتها | شو بتعرض |
|---|---|---|
| **أنواع التقييم** | إدارة فئات التقييم وترتيبها | ترويسة كبيرة داخل المحتوى («أنواع التقييم» + «إعداد التقييم») بدل عنوان الشريط العلوي، بطاقة عدّاد «6 أنواع التقييم»، بطاقة تلميح «اضغط واسحب لإعادة الترتيب»، ثم قائمة الأنواع القابلة للسحب. FAB إضافة |
| **إضافة فئة** (طبقة سفلية) | إنشاء نوع تقييم | عنوان «إضافة فئة»، حقل «اسم التقييم»، مفتاح «هذا هو الامتحان»، زر حفظ |
| **المقاييس الوصفية** | إدارة مقاييس التقييم الوصفي | قائمة المقاييس كبطاقات: الاسم + وسم «افتراضي» + قائمة إجراءات. FAB إضافة |
| **المقاييس الوصفية — إضافة/تعديل** | إنشاء أو تعديل مقياس وصفي | حقل «اسم المقياس» وحده، زر تأكيد (✓) في الشريط العلوي، وزر «حفظ» ثابت أسفل الشاشة |
| **المواد الدراسية** | استعراض مواد صف/فصل | مُنتقي الصف (صف علوي)، مبدّل الفصل (الأول/الثاني)، ثم قائمة المواد. FAB إضافة |

> شاشة «أنواع التقييم» هي الوحيدة في العيّنة كلها التي تضع العنوان داخل المحتوى لا في الشريط العلوي — الشريط يحمل سهم الرجوع فقط.

## الحقول

### فورم: إضافة فئة (طبقة سفلية — أنواع التقييم)

| الحقل | نوعه | إلزامي |
|---|---|---|
| اسم التقييم | نص، أيقونة أشكال | غير واضح — على الأرجح إلزامي |
| هذا هو الامتحان | مفتاح (Switch)، مطفأ افتراضياً | لا — له قيمة افتراضية |

### فورم: المقاييس الوصفية — إضافة/تعديل

| الحقل | نوعه | إلزامي |
|---|---|---|
| اسم المقياس | نص، أيقونة وسم | غير واضح — على الأرجح إلزامي |

> فورم بحقل واحد وزرَي تأكيد (✓ في الشريط العلوي + «حفظ» أسفل) — **ازدواج في الإجراء**؛ العلاقة بينهما غير موضّحة.
> لا يوجد في هذا الفورم أي حقل لمستويات المقياس (ممتاز / جيد جداً / …) رغم أن المقياس وصفي — انظر «غير واضح».

### فورمات غير مرصودة

- **إضافة/تعديل مادة دراسية** — الـ FAB موجود والشاشة غير ملتقطة في هذا الجزء.
- **تعديل نوع تقييم** — يُفترض عبر قائمة ⋮، والمحتوى غير مرصود.

## القوائم

### قائمة أنواع التقييم

البيانات الظاهرة بكل عنصر:
- مقبض سحب (⠿) على أقصى اليمين
- اسم النوع (مستمر، واجب منزلي، مذاكرة، مشاركة، مشروع، امتحان)
- وسم «فئة افتراضية» — يظهر على «مستمر» فقط
- زر قائمة إضافية (⋮)

بحث/فلتر/ترقيم: **لا شيء**. الترتيب يدوي بالسحب والإفلات — ولقطتان متتاليتان تُظهران «مستمر» و«واجب منزلي» متبادلَي الموضع، أي أن الترتيب يُحفَظ فعلاً.

### قائمة المقاييس الوصفية

البيانات الظاهرة بكل عنصر (بطاقة بخلفية):
- اسم المقياس («المقياس الافتراضي»)
- وسم «افتراضي»
- زر قائمة إضافية (⋮)

بحث/فلتر/ترقيم: لا شيء. عنصر واحد فقط في اللقطة، بلا مقبض سحب — أي **لا إعادة ترتيب هنا** خلافاً لأنواع التقييم.

### قائمة المواد الدراسية

البيانات الظاهرة بكل عنصر:
- مربّع أيقونة كتاب (يمين)
- اسم المادة (ديانة، علوم، لغة فرنسية، لغة انكليزية، لغة عربية)
- وسم طريقة التقييم («رقمي»)
- «درجة النجاح: 50»
- أيقونتا إجراء: حافظة (تقييمات) وكتاب برتقالي (**دلالته غير واضحة**)
- زر قائمة إضافية (⋮)

بحث/فلتر/ترقيم:
- **بحث**: لا يوجد
- **فلاتر**: مُنتقي الصف («علمي» بسهمَي أعلى/أسفل) + مبدّل الفصل الثنائي (الفصل الأول / الفصل الثاني) — القائمة **دائماً مفلترة** بصف وفصل، لا يوجد عرض «الكل»
- **ترقيم**: لا يوجد

## الأزرار

| الشاشة | الزر | شو بيعمل |
|---|---|---|
| أنواع التقييم | FAB (+) بلون Primary | يفتح طبقة «إضافة فئة» |
| أنواع التقييم | ⋮ على النوع | قائمة إجراءات النوع — **المحتوى غير مرصود** |
| أنواع التقييم | مقبض السحب ⠿ | إعادة ترتيب الأنواع |
| إضافة فئة | حفظ (أساسي، بعرض كامل) | ينشئ الفئة ويغلق الطبقة |
| إضافة فئة | مفتاح «هذا هو الامتحان» | يعلّم الفئة كفئة امتحان |
| المقاييس الوصفية | FAB (+) برتقالي | يفتح شاشة إضافة مقياس |
| المقاييس الوصفية | ⋮ على المقياس | قائمة إجراءات — **المحتوى غير مرصود** |
| إضافة مقياس | ✓ في الشريط العلوي | تأكيد/حفظ — علاقته بزر «حفظ» غير واضحة |
| إضافة مقياس | حفظ (أساسي، ثابت أسفل) | يحفظ المقياس |
| المواد الدراسية | مُنتقي الصف (سهما ⌃⌄) | يبدّل الصف المعروض |
| المواد الدراسية | مبدّل الفصل | يبدّل بين الفصل الأول والثاني |
| المواد الدراسية | أيقونة الحافظة على المادة | يفتح «التقييمات» للمادة (انظر [`03c2-academic.md`](03c2-academic.md)) |
| المواد الدراسية | أيقونة الكتاب البرتقالية | **غير معروف** |
| المواد الدراسية | ⋮ على المادة | قائمة إجراءات المادة — **المحتوى غير مرصود** |
| المواد الدراسية | FAB (+) بلون Primary | إضافة مادة جديدة |
| كل الشاشات | سهم الرجوع (←) | رجوع |

> لون الـ FAB يتبدّل بين الشاشات (Primary في أنواع التقييم والمواد، برتقالي في المقاييس الوصفية) — يؤكّد أن **معيار اللون غير معروف**.

## المكوّنات المشتركة

من [`00-design-system.md`](00-design-system.md):

- الشريط العلوي — شكل «عنوان + رجوع»، وشكل «عنوان + إجراء» (✓)، وشكل «سهم رجوع فقط» بلا عنوان (أنواع التقييم).
- بطاقة الإحصائية داخل القسم — التنويعة الممتلئة.
- بطاقة الترويسة داخل القسم.
- حقل النص (filled بأيقونة بادئة).
- المفتاح (Switch).
- المبدّل الشريطي — ثنائي (الفصل الأول/الثاني).
- حقل الاختيار (Selector) — مُنتقي الصف.
- الرقاقات: وسم («فئة افتراضية»، «افتراضي»، «رقمي»).
- عنصر القائمة (ListItem) — التنويعة الأساسية وتنويعة «بطاقة».
- الأزرار: أساسي ممتلئ، أيقونة، قائمة إضافية (overflow).
- زر الإجراء العائم (FAB).
- الطبقة السفلية (Bottom sheet) — تنويعة النموذج.

## جداول الداتابيز المتوقعة

| الجدول | الحقول المستنتجة |
|---|---|
| `assessment_types` | id، school_id، الاسم، ترتيب العرض، is_default، is_exam («هذا هو الامتحان») |
| `rubrics` (المقاييس الوصفية) | id، school_id، الاسم، is_default |
| `rubric_levels` | rubric_id، الاسم، القيمة، الترتيب — **مفترض**، لا فورم يدعمه في هذا الجزء |
| `subjects` (المواد) | id، grade_id، term_id، الاسم، طريقة التقييم (رقمي/وصفي)، الدرجة القصوى، درجة النجاح |

- المادة مرتبطة بـ **صف + فصل** معاً (القائمة مفلترة بالاثنين دائماً).
- `assessment_types` و`rubrics` على مستوى المدرسة لا الصف.

## غير واضح

1. **دلالة أيقونة الكتاب البرتقالية** على عنصر المادة.
2. **محتوى قوائم ⋮** في الشاشات الثلاث.
3. **مستويات المقياس الوصفي** — الفورم يحمل الاسم فقط؛ أين تُعرَّف المستويات (ممتاز/جيد/…)؟ ظهرت مستويات في شاشة «التقييمات» (انظر [`03c2-academic.md`](03c2-academic.md)) — **تناقض محتمل** في مكان تعريفها.
4. **ازدواج زرَي الحفظ** (✓ علوي + «حفظ» سفلي) في فورم المقياس.
5. **معنى «فئة افتراضية»** — هل تُختار تلقائياً عند إنشاء تقييم، أم لا يمكن حذفها.
6. **أثر مفتاح «هذا هو الامتحان»** على الحسابات (وزن، معدّل، كشف الدرجات).
7. **هل ترتيب أنواع التقييم عام للمدرسة** أم لكل مادة.
8. **هل يمكن إنشاء أكثر من مقياس وصفي** وربطه بمادة معيّنة — لا يوجد ربط ظاهر.
9. **إلزامية الحقول** في الفورمين.
10. **علاقة «طريقة التقييم» على المادة** (رقمي/وصفي) بالمقاييس الوصفية — الربط غير ظاهر.
11. **حدود المُنتقي**: هل يعرض كل الصفوف أم صفوف السنة الحالية فقط.
