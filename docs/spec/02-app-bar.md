# شاشات الشريط العلوي (AppBar)

المصدر: 6 صور في `docs/screens/app-bar/` — كلها بالثيم الداكن. الألوان مرجعها `00-design-system.md` ولم تُستخرج من هذه الصور.

---

## الشاشات

| الاسم | وظيفتها | شو بتعرض |
|---|---|---|
| الإشعارات | عرض إشعارات المستخدم | شريط علوي (عنوان "الإشعارات" + رجوع + قائمة ⋮)، صف رقائق تصفية أفقي (عرض الكل / سلوك / أعذار غياب / تسجيل)، ثم قائمة الإشعارات — في الصورة حالة فارغة: أيقونة جرس + "لا توجد إشعارات بعد" |
| إعدادات الإشعارات | تفعيل/تعطيل أنواع الإشعارات | عنوان "إعدادات الإشعارات" + رجوع، نص فرعي "اختر الإشعارات التي تريد استقبالها"، ثم قائمة بطاقات كل واحدة: أيقونة النوع + اسمه + مفتاح تبديل. أول بطاقة "تفعيل كل الإشعارات" (بلا أيقونة، مفتاح رئيسي) وتحتها: سلوك، أعذار غياب، تسجيل، حساب، رسائل، منشورات، جدول، نقل (القائمة قابلة للتمرير وقد تتضمن أنواعاً إضافية أسفلها) |
| المنشورات | تصفّح وإنشاء المنشورات | عنوان "المنشورات" + رجوع + أيقونة قائمة الموافقات، مبدّل شطري (منشوراتي / منشورات المدرسة)، صف رقائق فلاتر (النوع / نطاق الاستهداف / المادة)، قائمة المنشورات — في الصورة حالة فارغة: أيقونة مكبّر صوت + "لا منشورات بعد"، وزر عائم (+) أسفل اليسار |
| المنشورات — بعد التصفية | نفس الشاشة مع فلاتر مفعّلة | نفس ما سبق، لكن الرقائق المفعّلة تعرض القيمة المختارة مع زر (✕) للإزالة: "عام ✕"، "شعبة: علمي - إناث ✕"؛ ورقيقة "المادة" ما زالت بلا قيمة |
| اختيار نطاق الاستهداف (BottomSheet) | اختيار مستوى استهداف المنشور | ورقة سفلية فوق شاشة المنشورات: مقبض سحب، عنوان "نطاق الاستهداف" بشارة عمودية، ثم خيارات بصفوف: الكل، صف، شعبة، طالب، رحلة، مادة — كل خيار بأيقونة ونص |
| منشورات بانتظار الموافقة | مراجعة المنشورات المعلّقة | عنوان "منشورات بانتظار الموافقة" + رجوع فقط، قائمة المنشورات المعلّقة — في الصورة حالة فارغة: أيقونة قائمة مهام + "لا منشورات بانتظار الموافقة" |

## نقاط الدخول

| الشاشة | أي أيقونة بالشريط العلوي بتفتحها |
|---|---|
| الإشعارات | زر الجرس الدائري في شريط الرئيسية العلوي (اليسار) |
| المنشورات | زر مكبّر الصوت/الإعلانات الدائري في شريط الرئيسية العلوي (اليسار) |
| إعدادات الإشعارات | من شاشة الإشعارات: زر ⋮ (النقاط الثلاث) أقصى اليسار — **مفترض**، لم تُصوَّر القائمة المنسدلة نفسها |
| منشورات بانتظار الموافقة | من شاشة المنشورات: أيقونة قائمة المهام/الموافقات أقصى اليسار |
| اختيار نطاق الاستهداف | من شاشة المنشورات: النقر على رقيقة "نطاق الاستهداف" (ليست أيقونة شريط علوي) |
| الرجوع من أي شاشة منها | سهم الرجوع (←) أقصى يمين الشريط العلوي |

## الحقول

| الحقل | نوعه | إلزامي أو لا |
|---|---|---|
| تفعيل كل الإشعارات | Switch | لا (قيمة افتراضية = مفعّل) |
| سلوك / أعذار غياب / تسجيل / حساب / رسائل / منشورات / جدول / نقل | Switch لكل نوع | لا (كلها مفعّلة افتراضياً في الصورة) |
| مبدّل منشوراتي / منشورات المدرسة | Segmented toggle (خياران، واحد فقط) | إلزامي ضمنياً — دائماً أحد الخيارين محدّد، و"منشوراتي" هي الافتراضية |
| فلتر النوع | رقيقة اختيار (قيمة واحدة، قابلة للمسح) | لا |
| فلتر نطاق الاستهداف | رقيقة تفتح BottomSheet (قيمة واحدة، قابلة للمسح) | لا |
| فلتر المادة | رقيقة اختيار (قيمة واحدة) | لا |
| رقائق تصفية الإشعارات (عرض الكل / سلوك / أعذار غياب / تسجيل) | رقائق اختيار حصري (واحدة مفعّلة) | إلزامي ضمنياً — "عرض الكل" هي الافتراضية |
| خيار نطاق الاستهداف داخل الورقة السفلية (الكل / صف / شعبة / طالب / رحلة / مادة) | اختيار من قائمة (قيمة واحدة) | إلزامي عند فتح الورقة لإتمام الاختيار |

> لا توجد حقول نصية (TextField) ظاهرة في أي من الصور الستة.

## الجداول

لا توجد جداول بأعمدة في هذه الشاشات — كل العرض بقوائم بطاقات رأسية.

| القائمة | "الأعمدة" (حقول الصف) | بحث / فلتر / ترقيم |
|---|---|---|
| قائمة الإشعارات | غير معروفة (الشاشة فارغة في الصورة) | فلتر: رقائق النوع (عرض الكل / سلوك / أعذار غياب / تسجيل). لا بحث ولا ترقيم ظاهر — **غالباً تمرير لا نهائي، غير مؤكد** |
| قائمة أنواع الإشعارات (الإعدادات) | أيقونة، اسم النوع، مفتاح التبديل | لا بحث ولا فلتر ولا ترقيم — قائمة ثابتة قابلة للتمرير |
| قائمة المنشورات | غير معروفة (الشاشة فارغة في الصورة) | فلتر: مبدّل منشوراتي/المدرسة + رقائق النوع ونطاق الاستهداف والمادة. لا بحث ولا ترقيم ظاهر |
| قائمة منشورات بانتظار الموافقة | غير معروفة (فارغة) | لا فلتر ولا بحث ولا ترقيم ظاهر |
| خيارات نطاق الاستهداف | أيقونة + اسم الخيار | لا شيء |

## الأزرار

| الزر | شو بيعمل |
|---|---|
| سهم الرجوع (←) — شريط علوي يمين | يرجع للشاشة السابقة. موجود في الشاشات الستة كلها |
| ⋮ (نقاط ثلاث) — شريط الإشعارات يسار | يفتح قائمة خيارات — المرجّح أنها تحوي "إعدادات الإشعارات" و/أو "تعليم الكل كمقروء" — **المحتوى غير مصوَّر** |
| أيقونة الموافقات — شريط المنشورات يسار | يفتح شاشة "منشورات بانتظار الموافقة" |
| رقيقة "عرض الكل" (مفعّلة) | تلغي الفلترة وتعرض كل الإشعارات |
| رقائق "سلوك" / "أعذار غياب" / "تسجيل" | تفلتر الإشعارات حسب النوع |
| مفتاح "تفعيل كل الإشعارات" | يفعّل/يعطّل كل الأنواع دفعة واحدة (مفتاح رئيسي) |
| مفتاح كل نوع إشعار | يفعّل/يعطّل استقبال هذا النوع فقط |
| "منشوراتي" | يعرض منشورات المستخدم الحالي |
| "منشورات المدرسة" | يعرض منشورات المدرسة كاملة |
| رقيقة "النوع" | تفتح اختيار نوع المنشور (مثال القيمة المختارة: "عام") |
| رقيقة "نطاق الاستهداف" | تفتح الورقة السفلية لاختيار النطاق |
| رقيقة "المادة" | تفتح اختيار المادة |
| زر (✕) داخل الرقيقة المفعّلة | يمسح قيمة هذا الفلتر ويعيده لحالته الافتراضية |
| خيارات الورقة السفلية (الكل / صف / شعبة / طالب / رحلة / مادة) | تحدّد نطاق الاستهداف — وقد تفتح خطوة ثانية لاختيار العنصر المحدّد (مثلاً "شعبة: علمي - إناث") ثم تغلق الورقة وتطبّق الفلتر |
| زر عائم (+) أسفل اليسار — شاشة المنشورات | يفتح شاشة/نموذج إنشاء منشور جديد — **الشاشة الناتجة غير مصوَّرة** |

## المكوّنات المشتركة

من `00-design-system.md`:

- **الشريط العلوي (AppBar)** — بنفس المواصفات، مع فرق: هنا العنوان في الوسط وليس بجانب شعار على اليمين، وأزرار الأيقونات بلا خلفية دائرية (أيقونات مجرّدة) بخلاف شريط الرئيسية.
- **خلفية البطاقات والأسطح** ونصف قطر الزوايا — صفوف إعدادات الإشعارات وخيارات الورقة السفلية.
- **اللون الرئيسي (Primary / teal)** — عنوان الشريط العلوي، الرقيقة المفعّلة، المفاتيح المفعّلة، أيقونات الأنواع.
- **النص الأساسي** و**النص الثانوي / التسميات** — العناوين، النصوص الفرعية، نصوص الحالة الفارغة.
- **الحدود والفواصل** — إطار البطاقات والفاصل تحت عنوان الورقة السفلية.
- **لون التحذير** — لون الزر العائم (+).

مكوّنات جديدة غير موصوفة في `00-design-system.md` وتحتاج إضافة هناك:
Segmented toggle، Filter Chip (بحالتيها: فارغة / مفعّلة مع ✕)، Switch، BottomSheet بمقبض سحب، FloatingActionButton، حالة فارغة (Empty state: أيقونة رمادية كبيرة + نص).

## جداول الداتابيز المتوقعة

> استنتاج من الشاشات، وليس من مخطط فعلي.

| الجدول | حقول متوقعة | ملاحظات |
|---|---|---|
| `notifications` | id, user_id, type, title, body, payload/ref_id, is_read, created_at | `type` من مجموعة: سلوك، أعذار غياب، تسجيل، حساب، رسائل، منشورات، جدول، نقل |
| `notification_types` | code, label_ar, icon | قد تكون ثابتة بالكود بدل جدول |
| `notification_settings` | id, user_id, type_code, enabled | صف لكل مستخدم × نوع؛ "تفعيل الكل" قد يكون عموداً مستقلاً على المستخدم |
| `posts` | id, author_id, school_id, type, title, body, target_scope, target_id, subject_id, status (مسودة / بانتظار الموافقة / منشور / مرفوض), created_at, published_at | `status` يغذّي شاشة الموافقات |
| `post_targets` | post_id, scope (all/grade/section/student/trip/subject), target_id | لو كان الاستهداف متعدّداً؛ غير مؤكد إن كان مفرداً أم متعدّداً |
| `post_approvals` | post_id, reviewer_id, decision, note, decided_at | لدعم شاشة "بانتظار الموافقة" |
| `post_types` | code, label_ar | القيمة الظاهرة: "عام" |
| `grades` / `sections` | id, name (مثال الشعبة: "علمي - إناث") | مراجع الاستهداف |
| `students` | id, name, section_id | نطاق استهداف "طالب" |
| `trips` | id, name | نطاق استهداف "رحلة" |
| `subjects` | id, name | فلتر "المادة" ونطاق "مادة" |

## غير واضح

1. **قائمة ⋮ في شاشة الإشعارات** — محتواها غير مصوَّر؛ افتراض أن "إعدادات الإشعارات" تُفتح منها لم يُتحقّق.
2. **شكل عنصر الإشعار** — كل صور الإشعارات بحالة فارغة؛ الحقول المعروضة (عنوان، نص، وقت، مؤشر مقروء، إجراءات) غير معروفة.
3. **شكل بطاقة المنشور** — فارغة كذلك؛ لا نعرف ما يُعرض في الصف ولا إن كان فيه صور/مرفقات/تفاعلات.
4. **شاشة إنشاء منشور** (زر +) — غير مصوَّرة إطلاقاً: حقولها وإلزاميتها والتحقق منها كلها مجهولة.
5. **قائمة أنواع الإشعارات كاملة** — القائمة مقطوعة عند "نقل"؛ قد توجد أنواع إضافية أسفلها.
6. **تطابق الفلاتر** — رقائق تصفية الإشعارات (4 خيارات) أقل من أنواع الإشعارات في الإعدادات (8+)؛ سبب الاختلاف غير معروف.
7. **الاختيار المتعدد** — هل رقائق الفلاتر تقبل قيمة واحدة أم عدة قيم؟ الصور تُظهر قيمة واحدة لكل رقيقة فقط.
8. **الخطوة الثانية بعد اختيار "شعبة"** — كيف تُختار "علمي - إناث" بالضبط (ورقة ثانية؟ قائمة متداخلة؟) غير مصوَّر.
9. **الترقيم / التحميل التدريجي** لقوائم الإشعارات والمنشورات — لا دليل.
10. **الصلاحيات** — من يرى أيقونة الموافقات، ومن يستطيع النشر مباشرة دون موافقة؟ غير محدّد.
11. **نقطة دخول إعدادات الإشعارات** غير مؤكدة — قد تُفتح من الإعدادات العامة بدل شريط الإشعارات.
12. **الثيم الفاتح** لهذه الشاشات — غير مصوَّر.
