## الشاشات

| الاسم | وظيفتها | شو بتعرض |
|---|---|---|
| **إعدادات المدرسة** | تعديل هوية المدرسة | بطاقة شعار المدرسة (معاينة + زر تغيير)، حقل اسم المدرسة، حقل البريد الإلكتروني، زر حفظ بعرض كامل |
| **السنوات الأكاديمية** | استعراض السنة الدراسية وفصولها | بطاقة سنة واحدة: شارة «الحالي»، اسم السنة (2026-2027)، تاريخ البداية، تاريخ النهاية، ثم صف «الفصول الدراسية» قابل للطي بعدّاد، وتحته بطاقات الفصول |
| **الصفوف والشعب** | إدارة الصفوف وشعبها وترتيبها | تلميح «اضغط واسحب لإعادة الترتيب»، ثم قائمة بطاقات الصفوف؛ الصف الموسّع يعرض شعبه وزر «إضافة شعبة». FAB إضافة صف |
| **إضافة شعبة** (طبقة سفلية) | إنشاء شعبة داخل صف | عنوان «إضافة شعبة – <اسم الصف>»، حقل الشعبة، حقل السعة، زرَا إنشاء وإلغاء |
| **العطل والإجازات** | إدارة عطل التقويم | بطاقة ترويسة «التقويم والعطل / الإجازات»، ثم قائمة العطل (فارغة في اللقطة). FAB إضافة |

## الحقول

### فورم: إعدادات المدرسة

| الحقل | نوعه | إلزامي |
|---|---|---|
| شعار المدرسة | رفع صورة | غير واضح |
| اسم المدرسة | نص، أيقونة تخرّج | غير واضح — مملوء مسبقاً بـ «المعهد السوري» |
| البريد الإلكتروني | نص/بريد، أيقونة مظروف | غير واضح — فارغ في اللقطة |

### فورم: إضافة شعبة (طبقة سفلية)

| الحقل | نوعه | إلزامي |
|---|---|---|
| الشعبة | نص، أيقونة باب | غير واضح — على الأرجح إلزامي |
| السعة | رقم، أيقونة أشخاص | غير واضح |

> اسم الصف ليس حقلاً — يأتي من سياق البطاقة ويظهر في عنوان الطبقة.

### فورمات غير مرصودة

- **إضافة/تعديل صف** — الـ FAB موجود لكن الشاشة/الطبقة غير ملتقطة. الحقول المتوقّعة من بيانات البطاقة: اسم الصف، الرسوم.
- **إضافة/تعديل عطلة** — الـ FAB موجود والشاشة غير ملتقطة. الحقول المتوقّعة: الاسم، تاريخ البداية، تاريخ النهاية.
- **تعديل السنة الأكاديمية / الفصل** — لا يوجد أي زر تحرير ظاهر.

## القوائم

### قائمة الصفوف

البيانات الظاهرة بكل عنصر:
- مقبض سحب (⠿) على أقصى اليمين
- مربّع رقم الترتيب (1، 2، 3، 4)
- اسم الصف (علمي، أدبي، التاسع، الحادي عشر)
- «<n> شعب»
- «الرسوم: <مبلغ>» مع أيقونة نقود
- زر قائمة إضافية (⋮)
- سهم توسعة/طي (⌃ / ⌄)

عند التوسعة تظهر داخل البطاقة نفسها: ترويسة «الشُعب» + قائمة الشعب + زر «+ إضافة شعبة».

بحث/فلتر/ترقيم: **لا يوجد** — لا بحث ولا فلاتر ولا ترقيم صفحات. الترتيب يدوي بالسحب والإفلات.

### قائمة الشعب (داخل الصف الموسّع)

- مقبض سحب (⠿)
- مربّع أيقونة باب
- اسم الشعبة (إناث، ذكور)
- عدد الطلاب + أيقونة أشخاص (11، 13)
- زر قائمة إضافية (⋮)

بحث/فلتر/ترقيم: لا يوجد. الترتيب يدوي بالسحب.

### قائمة الفصول الدراسية (داخل بطاقة السنة)

- اسم الفصل (الفصل الأول / الفصل الثاني)
- نطاق التاريخ (بداية – نهاية)
- شارة «الحالي» للفصل الجاري فقط
- شريط عمودي بلون Primary على حافة الفصل الحالي

بحث/فلتر/ترقيم: لا يوجد. الصف الحاوي قابل للطي ويحمل عدّاداً (2).

### قائمة العطل

فارغة في اللقطة — بياناتها غير معروفة.

## الأزرار

| الشاشة | الزر | شو بيعمل |
|---|---|---|
| إعدادات المدرسة | تغيير الشعار (نصّي + أيقونة صورة) | يفتح منتقي صور الجهاز |
| إعدادات المدرسة | مربّع الرفع (أيقونة سحابة) | على الأرجح نفس فعل «تغيير الشعار» — **غير مؤكّد** |
| إعدادات المدرسة | حفظ (أساسي، أيقونة قرص) | يحفظ اسم المدرسة والبريد والشعار |
| كل الشاشات | سهم الرجوع (←) | يرجع لشاشة الإعدادات |
| السنوات الأكاديمية | سهم طي «الفصول الدراسية» | يفتح/يغلق قائمة الفصول |
| الصفوف والشعب | ⋮ على الصف | قائمة إجراءات الصف (تعديل/حذف — **المحتوى غير مرصود**) |
| الصفوف والشعب | ⋮ على الشعبة | قائمة إجراءات الشعبة — **المحتوى غير مرصود** |
| الصفوف والشعب | سهم توسعة الصف | يعرض/يخفي شعب الصف |
| الصفوف والشعب | + إضافة شعبة (إطار محدّد) | يفتح طبقة «إضافة شعبة» للصف نفسه |
| الصفوف والشعب | FAB (+) برتقالي | إضافة صف جديد |
| إضافة شعبة | إنشاء (أساسي) | ينشئ الشعبة ويغلق الطبقة |
| إضافة شعبة | إلغاء (محدّد الإطار بلون Primary) | يغلق الطبقة بلا حفظ |
| العطل والإجازات | FAB (+) برتقالي | إضافة عطلة جديدة |

> «إلغاء» هنا زر **محدّد الإطار (outlined)** بنص وإطار Primary — نوع غير مذكور في جدول الأزرار بـ `00-design-system.md`.

## غير واضح

1. **إلزامية الحقول** في كل الفورمات — لا نجوم ولا رسائل تحقّق ظاهرة.
2. **صيغة حقل الرسوم على الصف** ووحدته وموقع تعديله — يظهر في البطاقة ولا يوجد فورم ملتقط له.
3. **محتوى قوائم ⋮** للصف والشعبة.
4. **هل يمكن إنشاء أكثر من سنة أكاديمية** أو تعديلها/أرشفتها — اللقطة تُظهر سنة واحدة بلا أي زر إضافة.
5. **مصدر «الحالي»** — محسوب من التاريخ أم علم مخزّن.
6. **علاقة الرسوم بالصف** مقابل «أنواع الأقساط» في قسم الرسوم — قد يكون تكراراً أو حقلين مختلفين (**تناقض محتمل**).
7. **هل الشعبة مرتبطة بسنة أكاديمية** أم بالصف فقط — يؤثّر على ترحيل الطلاب بين السنوات.
8. **حدود حقل السعة** وهل يمنع تجاوزه عند إضافة طلاب.
9. **شاشات إضافة الصف والعطلة** غير ملتقطة.
