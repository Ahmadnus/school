## الشاشات

| الاسم | وظيفتها | شو بتعرض |
|---|---|---|
| **تسجيل الحضور — بلا شعبة** | حالة أولية | صف علوي: زر التاريخ (مفعّل، بلون Primary) + مُنتقي الشعبة، ثم حالة فارغة «اختر شعبة» |
| **تسجيل الحضور** | تسجيل حضور يومي لشعبة | نفس الصف العلوي، بطاقة تقدّم («11 الطلاب» + «3/11»)، قائمة الطلاب بمبدّل ثلاثي لكل طالب، شريط ملخّص سفلي رباعي، زر «تقديم الحضور» |
| **حضور البوابة** | تسجيل الحضور بمسح بطاقات NFC | سطر إرشادي «امسح بطاقات الطلاب عند وصولهم» + زر «مسح البطاقات» أسفل يسار |
| **حضور البوابة — لوحة المسح** (طبقة سفلية) | حالة المسح والبطاقات الممسوحة | عنوان «حضور البوابة»، شريط خطأ أحمر «خاصية NFC مغلقة – فعّلها من إعدادات الهاتف»، ثم «لم تُمسح أي بطاقة بعد» |
| **سجل الحضور** | استعراض سجلات الحضور السابقة | مُنتقي الشعبة، بحث، رقاقات فلترة حالة (الكل / حاضر / متأخر / بعذر / …)، ثم قائمة السجلات (فارغة في اللقطة) |
| **أعذار الغياب** | مراجعة أعذار الغياب المعلّقة | قائمة الأعذار (فارغة في اللقطة). لا شريط أدوات ولا FAB |

## الحقول

### فورم: تسجيل الحضور

| الحقل | نوعه | إلزامي |
|---|---|---|
| التاريخ | زر/مُنتقي تاريخ، قيمة مسبقة اليوم (2026-09-…) | نعم — له قيمة دائماً |
| الشعبة | قائمة منسدلة («اختر شعبة») | **نعم** — لا تظهر القائمة بدونها |
| حالة كل طالب | مبدّل ثلاثي: ح (حاضر) / م (متأخر) / غ (غائب) | لا — يمكن التقديم جزئياً (3/11) |

> المبدّل الثلاثي يلوّن الخيار المختار بدلالة الحالة: **ح** تركوازي، **م** برتقالي، **غ** أحمر فاتح؛ وغير المحدّد يبقى بلا تعبئة.
> شريط الملخّص السفلي يعرض **أربع** حالات (حاضر / متأخر / غياب مع عذر / غياب بلا عذر) بينما المبدّل يعرض **ثلاثاً** — انظر «غير واضح».

### فورم: سجل الحضور (فلترة لا إدخال)

| الحقل | نوعه | إلزامي |
|---|---|---|
| الشعبة | قائمة منسدلة، مملوءة «علمي - إناث» | نعم |
| بحث | نص، تلميح «بحث…» | لا |
| حالة | رقاقات فلترة (الكل / حاضر / متأخر / بعذر / عنصر رابع مقتطع) | لا — «الكل» افتراضياً |

### حضور البوابة

لا حقول إدخال — الإدخال كله عبر مسح NFC.

### فورمات غير مرصودة

- **تسجيل/تعديل عذر غياب** — لا يوجد زر إضافة في شاشة أعذار الغياب إطلاقاً؛ يبدو أن الأعذار **ترد من تطبيق الأهالي** لا تُنشأ هنا.
- **إجراء قبول/رفض العذر** — لا لقطة لعنصر عذر فعلي.

## القوائم

### قائمة طلاب تسجيل الحضور

البيانات الظاهرة بكل عنصر:
- أفاتار دائري بحرف واحد
- اسم الطالب
- رقمه (42، 39، 37، 36، 34)
- مبدّل ثلاثي (ح / م / غ) على اليسار

الفلترة: تاريخ + شعبة (إلزاميان). لا بحث ولا ترقيم.
بطاقة التقدّم أعلى القائمة: عدد الطلاب + «<مُسجَّل>/<الكل>».

### قائمة سجلات الحضور

فارغة في اللقطة — بيانات العنصر **غير معروفة**.
بحث/فلتر/ترقيم: شعبة (منسدلة) + بحث + رقاقات حالة. لا ترقيم. **لا يوجد فلتر تاريخ أو نطاق تاريخي** رغم أنها شاشة سجل تاريخي.

### قائمة أعذار الغياب

فارغة في اللقطة — بيانات العنصر غير معروفة. لا بحث ولا فلاتر ولا ترقيم.

### قائمة البطاقات الممسوحة (حضور البوابة)

فارغة — «لم تُمسح أي بطاقة بعد». تُبنى لحظياً من عمليات المسح.

## الأزرار

| الشاشة | الزر | شو بيعمل |
|---|---|---|
| تسجيل الحضور | زر التاريخ (ممتلئ Primary، أيقونة تقويم) | يفتح منتقي التاريخ |
| تسجيل الحضور | مُنتقي الشعبة | يفتح اختيار الشعبة |
| تسجيل الحضور | مبدّل ح/م/غ لكل طالب | يحدّد حالة الطالب ويحدّث الملخّص السفلي فوراً |
| تسجيل الحضور | تقديم الحضور (أساسي، أيقونة شخص بعلامة ✓) | يحفظ حضور اليوم للشعبة |
| حضور البوابة | مسح البطاقات (أساسي، أيقونة NFC) | يفتح لوحة المسح السفلية ويبدأ الاستماع لـ NFC |
| سجل الحضور | مُنتقي الشعبة | يبدّل الشعبة |
| سجل الحضور | رقاقات الحالة | تفلتر السجلات |
| كل الشاشات | سهم الرجوع (←) | رجوع |

> **لا يوجد FAB في أي من شاشات هذا القسم** — خلافاً لكل الأقسام السابقة.

## المكوّنات المشتركة

من [`00-design-system.md`](00-design-system.md):

- الشريط العلوي — شكل «عنوان + رجوع».
- حقل الاختيار (Selector) — مُنتقي الشعبة.
- حقل البحث.
- الرقاقات: فلتر مفعّل/غير مفعّل، فلتر مع أيقونة (رقاقات الحالة تحمل أيقونة قبل النص).
- المبدّل الشريطي — التنويعة **الثلاثية المضغوطة** داخل عنصر القائمة.
- بطاقة الإحصائية داخل القسم — التنويعة الخافتة.
- عنصر القائمة (ListItem) — التنويعة الأساسية.
- شريط الملخّص السفلي — أربعة أعمدة.
- الأزرار: أساسي ممتلئ.
- الطبقة السفلية (Bottom sheet) — تنويعة لوحة حالة (ليست نموذجاً ولا قائمة اختيار).
- الحالة الفارغة.

مكوّن جديد لم يُوثَّق سابقاً:

- **شريط خطأ ممتلئ (Error banner)**: بطاقة بعرض كامل بخلفية **حمراء ممتلئة** ونص أبيض وأيقونة على اليمين، زوايا ~12dp. يختلف عن «التنبيه داخل المحتوى» البرتقالي ذي الإطار. أضفتُه للمرجع.

## قوائم فارغة

| القائمة | شو المتوقع تعرضه |
|---|---|
| **تسجيل الحضور — بلا شعبة** | أيقونة كتاب بعلامة مرجعية، عنوان «اختر شعبة»، سطر ثانوي «اختر فصلاً دراسياً لعرض طلابه» |
| **سجل الحضور** | أيقونة تقويم بعلامة ✕، عنوان «لا توجد سجلات حضور». بلا سطر ثانوي وبلا إجراء |
| **أعذار الغياب** | أيقونة قائمة بعلامة ✓، عنوان «لا توجد أعذار»، سطر ثانوي «لا توجد أعذار معلقة» |
| **البطاقات الممسوحة** | سطر نصّي فقط «لم تُمسح أي بطاقة بعد» — بلا أيقونة ولا عنوان (ليست حالة فارغة كاملة) |

> السطر الثانوي في «اختر شعبة» يقول **«اختر فصلاً دراسياً»** بينما العنوان والحقل يقولان **«شعبة»** — تعارض في المصطلح.

| الجدول | الحقول المستنتجة |
|---|---|
| `attendance_records` | id، student_id، section_id، التاريخ، الحالة (حاضر/متأخر/غياب بعذر/غياب بلا عذر)، مصدر التسجيل (يدوي/بوابة)، من سجّله، وقت التسجيل |

## غير واضح

1. **ثلاث حالات في المبدّل مقابل أربع في الملخّص** — كيف يُفرَّق «غياب مع عذر» عن «غياب بلا عذر»؟ على الأرجح تُشتق من وجود عذر مقبول في `absence_excuses`، لا من اختيار المستخدم — **غير مؤكّد**.
2. **«اختر فصلاً دراسياً» مقابل «شعبة»** — تعارض مصطلحات في نفس الشاشة.
3. **بيانات عنصر سجل الحضور** — القائمة فارغة في اللقطة.
4. **بيانات عنصر عذر الغياب** وإجراءات القبول/الرفض.
5. **من ينشئ الأعذار** — لا زر إضافة؛ يُرجَّح ورودها من تطبيق الأهالي (خارج هذه المواصفة).
6. **غياب فلتر التاريخ** في سجل الحضور رغم كونه سجلاً تاريخياً.
7. **الرقاقة الرابعة المقتطعة** في فلاتر سجل الحضور (تظهر أيقونة ✕ فقط) — على الأرجح «غائب» أو «بلا عذر».
8. **هل يمكن تعديل حضور يوم سابق** بعد التقديم.
9. **علاقة حضور البوابة بتسجيل الحضور اليدوي** — هل المسح يملأ نفس السجل، وماذا لو تعارضا.
10. **ربط بطاقة NFC بالطالب** — لا شاشة لإصدار/ربط البطاقات في أي مجلد.
11. **هل الحضور على مستوى اليوم أم الحصة** — التاريخ فقط ظاهر، بلا اختيار حصة (بينما الجدول الدراسي يعرّف حصصاً) — **تناقض محتمل** مع [`03c2-academic.md`](03c2-academic.md).
12. **سلوك التقديم الجزئي** — هل يُحفظ غير المحدّدين كـ null أم يُرفض التقديم.
