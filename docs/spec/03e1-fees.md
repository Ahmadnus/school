## الشاشات

| الاسم | وظيفتها | شو بتعرض |
|---|---|---|
| **أنواع الأقساط** | إدارة أنواع الأقساط مجمّعة حسب الصف | عنوان قسم «حسب الصف»، ثم مجموعات بعنوان اسم الصف؛ كل مجموعة تحوي بطاقات أنواع الأقساط. زر «+ إضافة نوع قسط» عائم أسفل يسار |
| **إضافة نوع قسط** | إنشاء نوع قسط وجدول دفعاته | ثلاث بطاقات تجميع: (1) الهوية — الاسم، الصف، مفتاح قسط النقل، المادة؛ (2) المالية — المبلغ الإجمالي، ملاحظات؛ (3) جدول الأقساط — دفعات + «إضافة دفعة» + سطر مجموع. زر حفظ |
| **اختر صفاً** (طبقة سفلية) | اختيار صف للقسط | عنوان «اختر صفاً» + قائمة تبدأ بـ **«بدون صف»** ثم الصفوف (علمي، أدبي، …) |
| **اختر مادة** (طبقة سفلية) | ربط القسط بمادة | عنوان «اختر مادة» + قائمة المواد، كل عنصر: اسم المادة + الصف تحته |

> «إضافة نوع قسط» و«اختر صفاً/مادة» ملتقطة في ثلاث حالات تمرير مختلفة؛ اعتُبرت شاشة واحدة.

## الحقول

### فورم: إضافة نوع قسط — بطاقة الهوية

| الحقل | نوعه | إلزامي |
|---|---|---|
| اسم نوع القسط | نص، أيقونة وسم | غير واضح — بلا نجمة |
| الصف | صف اختيار يفتح طبقة سفلية، افتراضي **«بدون صف»** | لا — له قيمة افتراضية |
| قسط النقل | مفتاح (Switch)، مطفأ افتراضياً | لا |
| المادة | صف اختيار يفتح طبقة سفلية («اختر مادة»)، تحت عنوان فرعي «المادة» | **لا** — يظهر زر مسح بعد الاختيار |

### فورم: إضافة نوع قسط — بطاقة المالية

| الحقل | نوعه | إلزامي |
|---|---|---|
| المبلغ الإجمالي | رقم، أيقونة نقود | غير واضح — على الأرجح إلزامي |
| ملاحظات | نص متعدد الأسطر | لا |

### فورم: إضافة نوع قسط — جدول الأقساط (صفوف متكرّرة)

لكل دفعة بطاقة داخلية:

| الحقل | نوعه | إلزامي |
|---|---|---|
| تاريخ القسط | مُنتقي تاريخ، أيقونة تقويم | غير واضح |
| المبلغ | رقم | غير واضح |
| ملاحظات (اختياري) | نص | **لا** — مصرّح نصّاً |

- عنوان البطاقة الداخلية «القسط <n>» بلون Primary + أيقونة حذف حمراء.
- أسفل الدفعات: زر «+ إضافة دفعة» وسطر مجموع تحقّق **«المجموع: 0 من 0»** بلون أخضر — يقارن مجموع الدفعات بالمبلغ الإجمالي.
- الجدول يبدأ **فارغاً** (بلا أي دفعة) في اللقطة الأولى، والدفعة الأولى تُضاف يدوياً.

> تعارض بين اللقطتين: في إحداهما «جدول الأقساط» يحوي زر «+ إضافة دفعة» فقط، وفي أخرى يحوي «القسط 1» بحقوله — أي أن الجدول يبدأ فارغاً ثم تُضاف الصفوف.

### فورمات غير مرصودة

- **تعديل نوع قسط** — يُفترض عبر ⋮، غير مرصود.

## القوائم

### قائمة أنواع الأقساط

مجمّعة بعنوان **الصف** (أدبي، علمي، البكالوريا الأدبي شباب، الحادي عشر، التاسع، البكالوريا الادبي البنات…).

البيانات الظاهرة بكل بطاقة:
- اسم القسط (مقتطع: «القسط ا…»)
- رقاقة حالة: **«افتراضي»** (Primary) أو **«متوقف»** (رمادي — والبطاقة كلها تبدو باهتة)
- رقاقة الصف
- المبلغ بلون Primary مع العملة («8000000.00 ل.س»)
- «<n> خطط مرتبطة» — لا تظهر لكل البطاقات (غائبة عن «الحادي عشر»)
- زر قائمة إضافية (⋮)

بحث/فلتر/ترقيم: **لا شيء**. التجميع حسب الصف فقط، والترتيب غير واضح المعيار.

### قائمة اختيار الصف (طبقة سفلية)

- مربّع أيقونة + اسم الصف + سهم. العنصر الأول **«بدون صف»** بأيقونة مختلفة (إطار متقطّع).
- بلا بحث ولا فلتر. **لا يعرض عدد الشعب** خلافاً لطبقة «اختر صفاً» في القسم الأكاديمي — انظر «غير واضح».

### قائمة اختيار المادة (طبقة سفلية)

- مربّع أيقونة كتاب + اسم المادة + الصف تحته + سهم.
- تعرض المادة مكرّرة باسم واحد لصفوف مختلفة (ديانة/علمي، ديانة/أدبي).
- بلا بحث ولا فلتر — وقد تطول كثيراً.

## الأزرار

| الشاشة | الزر | شو بيعمل |
|---|---|---|
| أنواع الأقساط | + إضافة نوع قسط (زر ممتد برتقالي، أسفل يسار) | يفتح «إضافة نوع قسط» |
| أنواع الأقساط | ⋮ على البطاقة | قائمة إجراءات النوع (تعديل/إيقاف/حذف؟) — **المحتوى غير مرصود** |
| إضافة نوع قسط | صف «الصف» (سهم ‹) | يفتح طبقة «اختر صفاً» |
| إضافة نوع قسط | صف «المادة» (سهم ‹) | يفتح طبقة «اختر مادة» |
| إضافة نوع قسط | زر مسح المادة | يلغي ربط المادة (ظاهر في اللقطة الأولى للقسم) |
| إضافة نوع قسط | مفتاح «قسط النقل» | يعلّم القسط كقسط نقل |
| إضافة نوع قسط | + إضافة دفعة (نصّي) | يضيف صف دفعة جديد للجدول |
| إضافة نوع قسط | أيقونة الحذف الحمراء على الدفعة | يحذف الدفعة |
| إضافة نوع قسط | حفظ (أساسي، بعرض كامل) | يحفظ نوع القسط وجدوله |
| كل الشاشات | سهم الرجوع (←) | رجوع |

> زر الإضافة هنا **زر ممتد (extended FAB)** بنص وأيقونة، لا FAB مربّع — أول ظهور له في العيّنة.

## غير واضح

1. **إلزامية كل الحقول** — لا نجوم في هذا الفورم إطلاقاً، خلافاً لفورم «مادة جديدة».
2. **معنى «افتراضي»** على نوع القسط — هل يُسند تلقائياً لكل طالب في الصف.
3. **معنى «متوقف»** ومن يوقفه وأثره على الخطط المرتبطة القائمة.
4. **معيار ترتيب المجموعات** (الصفوف) في القائمة — ليس أبجدياً ولا مطابقاً لترتيب الصفوف في [`03a-school-setup.md`](03a-school-setup.md).
5. **علاقة «المبلغ الإجمالي» هنا بحقل «الرسوم» على الصف** في `03a` — **تناقض محتمل**: مصدران للرقم نفسه.
6. **سلوك سطر «المجموع: 0 من 0»** — هل يمنع الحفظ عند عدم التطابق؟ لا دليل.
7. **ربط القسط بمادة** — لماذا؟ قسط لمادة معيّنة (كمادة اختيارية)؟ الغرض غير موضّح.
8. **«بدون صف»** — قسط عام لكل المدرسة؟ وكيف يُسند؟
9. **مفتاح «قسط النقل»** — القسم خارج النطاق، لكن المفتاح موجود هنا؛ أثره غير معروف.
10. **غياب عدد الشعب** في طبقة «اختر صفاً» هنا مقابل وجوده في نفس الطبقة بالقسم الأكاديمي — تنويعتان لنفس المكوّن.
11. **ماذا يحدث للخطط المرتبطة** عند تعديل المبلغ أو جدول الدفعات لاحقاً.
12. **العملة** — ثابتة أم قابلة للإعداد.
13. **محتوى قائمة ⋮**.
