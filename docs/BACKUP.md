# النسخ الاحتياطي والاستعادة

- `php artisan db:backup` — نسخة مضغوطة في `storage/app/backups/backup-YYYYmmdd-HHMMSS.sql.gz`.
- يعمل يومياً 02:00 عبر المُجدوِل (يلزم `* * * * * php artisan schedule:run` في cron).
- التدوير: يُحذف ما تجاوز 14 يوماً، ويبقى دائماً أحدث 3 نسخ.
- النسخة تُعتمد فقط إن اكتمل ختام mysqldump.
- **انسخ الملفات خارج الخادم** (جهازك أو تخزين سحابي) دورياً: نسخة على القرص نفسه لا تحمي من فقدان الخادم.

## الاستعادة (على قاعدة جديدة أو بعد إيقاف التطبيق)
```
gunzip -c backup-YYYYmmdd-HHMMSS.sql.gz | mysql -u USER -p DATABASE
```
جرّب الاستعادة على قاعدة مؤقتة أولاً قبل الاعتماد على أي نسخة.

## سجلّ التدقيق
`audit_logs`: من غيّر ماذا ومتى، بقيمه القديمة والجديدة. للإضافة فقط. واجهة القراءة:
`GET /api/audit-logs` (للإدارة فقط) بمرشّحات `type`, `target_id`, `user_id`, `event`, `from`, `to`.
